# Thoughts on Twitterviewer.net?

## Problem

Now that Nitter, XCancel, and Twitterwebviewer are gone, it seems to be the best website like that still around.One thing (which some people don’t seem to realize) is that you have to go to advanced search on the website to search by term rather than search by profile. On your phone, you have to use the 3 dots on the top left to open the menu that has advanced search. Once you figure that out, I don’t really find it that complicated to use.Twitterviewer does have a lot of ads, but then again X itself has a lot of ads too.
