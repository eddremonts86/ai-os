# SPEC.md — CantonPay – registration-free Stellar payment links

## Problem

I built CantonPay because I wanted a simple way to accept Stellar payments without creating a merchant account.<p>You can create a payment link without registering, send it to someone, and receive the payment directly to your Stellar wallet.<p>It also has an API and webhooks for integrating payments into an application.<p>The current version is running on Stellar Testnet, so there’s no real money involved.<p>I’d especially like feedback from developers who have built payment flows on Stellar.
