# SPEC.md — A skill that makes people think you're using Claude Code

## Problem

Built a skill that makes people think you&#x27;re using Claude Code.<p>Sometimes when browsing repositories on GitHub, you might notice &quot;Claude&quot; listed as a co-author or contributor in commit histories and PRs.<p>This skill lets repositories that aren&#x27;t using Claude Code mimic that exact look.<p>To make the mimicry as authentic as possible, I analyzed dozens of real-world commits and PRs, and studied Claude Code&#x27;s binary behavior and output patterns. It now replicates Claude&#x27;s commit dialect, RFC 2822 trailers, and PR style almost 1:1.<p>GitHub: <a href="https:&#x2F;&#x2F;github.com&#x2F;Juwan-Hwang&#x2F;claude-mimic" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;Juwan-Hwang&#x2F;claude-mimic</a><p>Now any code can look like it was authored by Claude. Built purely for fun and entertainment! :)
