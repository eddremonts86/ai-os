# npx x402-hosting deploy – hosting NextJS with a single cmd

## Problem

Hi HN,Creator here of x402-hosting. The idea is that vibe-coded projects need hosting too! Some friends of mine asked how to convert a .tsx file into a link, and that got me thinking. Wouldn’t it be great if you could just ask the agent itself to deploy the project for x amount of months and return a live URL...Maybe agents will start using this, maybe not. At least it was a great excuse to play around with the x402 payment-required protocol.
