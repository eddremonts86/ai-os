# Witstep – daily math and logic puzzle game (Free No Sign-up)

## Problem

The poster built Witstep, a free daily math and logic puzzle game with a 'patterns' mode and no sign-up. They note it already has many patterns and they will expand over time.

## Objective

Offer a free, sign-up-free daily math and logic puzzle game, including a patterns mode.

## Target Users

Casual puzzle fans who want a daily mental warm-up with no account required.

## MVP Scope

A static web app that serves one new daily puzzle plus a patterns mode, playable without an account.

## Design Direction

See `DESIGN.md` for this project's design tokens.

## Constraints

Puzzle variety has to keep up with daily cadence to stay interesting.
