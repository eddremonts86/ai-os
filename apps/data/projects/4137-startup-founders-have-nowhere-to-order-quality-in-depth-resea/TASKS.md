# Startup founders have nowhere to order quality, in-depth research on specific projects or niches — existing services provide superficial and unreliable reports

## Phase 0: Scaffold

- [x] Capture problem from ProblemHunt + write SPEC.md skeleton
- [ ] Provision Coolify app + Drizzle migrations + Stripe Connect platform application
- [ ] First 20 vetted researchers onboarded (track-record check)

- [ ] Manual matching console for the human reviewer

## Phase 1: Core

- [ ] Standard report template: executive summary + source-cited claims + methodology + opposing view + raw-source appendix
- [ ] Source-citation pre-processor: flags every URL in the draft, requires reviewer "verified" mark before delivery
- [ ] 2-pass review: researcher draft → reviewer verifies citations → founder delivery
- [ ] Opposing-view section: required template section before reviewer can mark "verified"
- [ ] Founder pre-brief call (separately billed) to align on the deliverable spec
- [ ] Stripe Connect escrow: $500 / $1,500 / $3,000 tiers, 7-day auto-approve
- [ ] Researcher payout: 60% on founder approval or 7-day auto-approve window
- [ ] End-to-end test: founder brief → matched → drafted → reviewed → delivered → approved → paid out

## Phase 2: Deploy

- [ ] Coolify production deploy with daily SQLite backup
- [ ] Per-researcher satisfaction rating surfaced in the matching console
- [ ] First-3-briefs probation with mandatory review
- [ ] Random spot-check of delivered reports by a separate reviewer; 1 confirmed bypass = researcher removed
- [ ] Researcher cohort expansion cadence (quarterly rubric review)
- [ ] Post-mortem at week 14: do delivered reports actually change founder decisions, or are they shelf-ware?
