# I built a visual API test builder - looking for honest feedback

> Auto-enriched product brief.

## Value Proposition

A visual API test builder that lets non-engineers construct and run API tests with drag-and-drop nodes.

## Target Users

- QA teams without deep coding skills
- Product managers who want to validate API behaviour
- Solo founders testing their own APIs without writing code

## Jobs To Be Done

When I want to test an API without writing code, I want a visual builder where I drag in nodes for request, assertion, and response, so I can run a test in minutes.

## Success Metrics

- At least 100 non-engineer users in pilot
- Median test-build time below 10 minutes
