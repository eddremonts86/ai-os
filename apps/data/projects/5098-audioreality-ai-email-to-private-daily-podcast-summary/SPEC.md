# SPEC.md — Audioreality.ai – email to private daily podcast summary show

## Problem

Hey all,<p>TLDR: When you sign up you get an email alias @audioreality.ai that you can use to sign up for newsletters, have agents send output to, etc. Once a day you get a private podcast with a multi-host format&#x2F;conversation, so it’s not a basic summary and it’s not a verbatim readout. You can configure multiple shows too, so I personally have some based on different subjects I’m interested in.<p>I built this because I have much more opportunity to listen to content than sit and read (exercising, commuting, background noise), but I find a lot of really valuable newsletters out there. So I’ve been trying to dial in a tolerable AI-generated format to get the info out in a way that’s easy for me to consume.<p>This opened a few adjacent use cases like having scheduled agents email research, Google News style updates, etc. (even top HN feed stuff).<p>I’d love feedback on the format approach, the script quality, “host” behaviors&#x2F;personalities, and anything else. The audio quality is a constant work in progress as I test different audio models (and I completely understand if audio AI totally creeps you out).<p>Thanks!
