# Skybits – A document editor for humans and agents

## Problem

Our business team were heavy users of ChatGPT's canvas feature, but it wasn't very useful once we needed to share a canvas and edit it collaboratively. Some team members were also using a different AI, and we couldn't find a good way to work on docs without sending each other .md files. So we built Skybits to solve that problem. It's free, AI-agnostic, and supports documents, spreadsheets, and HTML.
