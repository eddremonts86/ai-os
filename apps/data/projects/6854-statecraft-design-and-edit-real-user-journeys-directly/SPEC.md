# SPEC.md — Statecraft – Design and edit real user journeys directly on your live codebase

## Problem

Statecraft is a design tool that runs on your real product, mapping live user journeys from your repository and letting you edit them directly. It reconstructs flows from actual React or Vue components, props, and tokens so teams visualize every state, branch, and error path, even in complex journeys. You can iterate by dragging on a canvas, tweaking code in your IDE, or guiding an agent, then share click-through links for feedback. Continuous integration keeps designs and frontend in sync so changes can be shipped with confidence. View startup
