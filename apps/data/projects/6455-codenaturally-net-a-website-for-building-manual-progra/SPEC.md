# SPEC.md — Codenaturally.net, a website for building manual programming fluency

## Problem

I made this website to be an environment for graduated recall practice and testing of programming fluency with various languages&#x2F;tools.<p>I write a lot less manual code these days, but I don&#x27;t like being too reliant on agents to do everything for me; I like to keep my fluency with some of the languages &#x2F; tools I value the most.  So this website helps me practice in those languages and retain and build my fluency.<p>Hoping it might help others who feel similarly do the same.
