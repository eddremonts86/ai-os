# SPEC.md — Find Right Plugin – Find Right Plugin matches users to the right plugin in 60 seconds

## Problem

Find Right Plugin is a free, quiz-based tool that matches WordPress and Jira/Atlassian users to the right plugin based on their specific problem and role instead of a generic top 10 listicle. Answer three quick questions with no sign-up required and get a shortlist suited to your situation in about 60 seconds. View startup
