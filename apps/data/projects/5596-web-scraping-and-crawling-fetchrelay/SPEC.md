# SPEC.md — Web Scraping and Crawling – FetchRelay

## Problem

Hey everyone. I am Suraj - building FetchRelay. FetchRelay converts public webpages into structured data - md, text, links.. Features include single page extraction, running crawl jobs, batch jobs, and webpage change monitoring.<p>You can try it out via the browser based workbench, API, or MCP for agents. There are also some nice tools you can try out : website to markdown, website to text and,  url extractor.
Extraction works with HTTP fetching and browser rederning. ou can also run crawl, batch jobs, and page monitors. The webparser integration is generic and works for a lot of a pages. I&#x27;m still working on login failures and captcha touchpoints.<p>Do try it out and integrate it in your workflows - would appreciate the feedback. You get free monthly credits. 
Happy to answer questions on the implementation. Thanks.
