# SPEC.md — Pushie – Get notified with a simple webhook

## Problem

Pushie lets you send notifications to yourself from anywhere. Create an account, claim a username, and start pushing to every device you are signed in on with a single HTTP request.<p>No app or SDK to install. No complex authentication. Just a HTTP POST request with your message.
