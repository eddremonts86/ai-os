# SPEC.md — SEO Score API – Run fast, scored SEO audits for any URL via a simple REST API

## Problem

SEO Score API provides a hosted REST API that delivers a scored SEO audit for any URL in seconds. It runs 82 checks covering on-page and technical SEO, social metadata, performance, accessibility, AI readability, and SXO/AEO/AIO scoring. The results include clear pass, warn, or fail outcomes with fixes and a 0–100 score. Developers integrate it into code, CI/CD, and AI agents, while agencies use batch audits, history, and reporting. A Deep Site Audit with 14,000+ checks is launching in private beta for Pro and Agency plans. View startup
