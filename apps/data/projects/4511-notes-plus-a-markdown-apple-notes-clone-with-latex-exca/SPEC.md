# SPEC.md — Notes Plus – A Markdown Apple Notes Clone with Latex, Excalidraw etc.

## Problem

tldr: clone of Apple Notes, but every note is a local Markdown file.<p>Hi, I used a summer of unemployment to actually finalize a hobby project, a literal clone of Apple&#x27;s Notes, with open access to the filesystem, meaning each note is just a markdown file. Then implemented renderers for Excalidraw, Latex, AsciiMath, mermaid diagrams, PlantUML, Graphviz, Vega Lite, mhchem and footnotes (a feature i need a lot in texts).<p>It can also show notes in vertical lists, like swimlanes, I call it &quot;JIRA view&quot; ;)<p>Free for now (might monetize later if anybody is actually interested in the tool, with $19 one-time payment, NOT subscription)!<p>macOS app, but Windows and Linuxes are planned too.<p>I&#x27;m not 100% sure about the legal aspect of this, but i will try to even list it in the Appstore.
The binaries are signed &#x2F; notarized by Apple.<p>*PLEASE NOTE:* This is an early alpha!
