# OutFund – a leaderboard where indie projects can raise funds

## Value Proposition

A public leaderboard where indie projects pitch and raise funds from the crowd — visibility and backing in one place. The leaderboard framing is the point: projects compete in public, and backers see both the pitch and the money. The capture is a bare link, so the value here is the title's promise, not a working description.

## Jobs To Be Done

1. **Functional job** — List an indie project with a pitch and funding state.
2. **Functional job** — Rank projects on a public leaderboard by a stated rule.
3. **Functional job** — Accept public contributions into a project.
4. **Emotional job** — Be seen: indie projects compete on merit, not network alone.

## Success Metrics

- **Listed projects** and the share with at least one contribution.
- **Funds raised** per project (total and median).
- **Leaderboard conversion:** visits that become contributions.
- **Backer return rate:** backers who fund more than one project.
