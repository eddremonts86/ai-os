# SPEC.md — SafeHabits – Build measurable security habits and generate audit-ready evidence

## Problem

SafeHabits is a fully managed human risk management platform designed for SOC 2, ISO 27001, NIS2, and NIST CSF compliance. You upload a CSV of your people and it handles everything: practical lessons that build seven employee habits and three governance habits for leadership, gentle nudging, and audit-ready evidence ready for upload to Vanta and Drata. It compares self-rated confidence with first-attempt understanding to reveal overconfidence and track program effectiveness. Every lesson is created by security practitioners, never AI-generated.
