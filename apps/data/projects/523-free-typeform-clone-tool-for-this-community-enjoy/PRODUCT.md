# "FREE Typeform clone tool for this community. Enjoy!"

> Auto-generated product brief. Review and refine before MVP scoping.

## Value Proposition

A community member can build a polished one-question-at-a-time form, share it, and get 1,000 responses/month free, without a Typeform subscription — and the community can self-host it if they want.

## Target Users

| Stakeholder | Why they care |
|---|---|
| Community member | Needs to run a survey without paying for a SaaS. |
| Community moderator | Wants RSVPs and polls without learning a new tool. |
| Community admin (self-host) | Wants to run the tool on their own infra for data sovereignty. |

## Jobs To Be Done

1. **Functional job** — Run a survey without paying.
2. **Emotional job** — Feel that the form looks as polished as a paid tool's output.
3. **Social job** — Be able to share the form without a "free plan" watermark.

## Success Metrics

- **Adoption:** ≥100 forms created by community members in the first 60 days.
- **Responses:** ≥1,000 responses/day across the active forms within 90 days.
- **Self-host:** ≥5 community-run instances live within 120 days.

## Pricing & Monetization

Free for everyone, forever. Optional "support the project" link to a GitHub Sponsors page.

## Competitive Landscape

- **Typeform, Tally, Google Forms** — paid or ad-supported, with limits on the free tier.
- **Formbricks, SurveyJS** — open-source, but heavier setup than a single Docker run.
- **DIY Google Forms** — works, doesn't match the one-question UX.
