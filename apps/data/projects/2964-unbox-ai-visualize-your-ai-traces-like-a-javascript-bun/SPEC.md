# Unbox-AI Visualize your AI traces like a JavaScript bundle

## Problem

When building AI agents, I found myself struggling to understand what exactly is happening inside of all of our traces. I was pasting huge JSON files to my AI agent to parse and get some useful insights from it. Then I thought, Webpack bundle visualizer had this great view to see all your dependencies - what if we could visualize AI context from traces like this? So I built unbox-ai.It's just one command: npx unbox-ai trace.jsonIt also ships with an agent skill so your AI agent doesn't need to parse through a huge JSON file to analyze a trace.Let me know what you think!
