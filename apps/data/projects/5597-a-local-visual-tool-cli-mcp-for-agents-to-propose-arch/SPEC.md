# SPEC.md — A local visual tool cli/mcp for agents to propose architecture changes

## Problem

Author here. I built this because I&#x27;ve always had a hard time focusing on large swathes of pure text. I love visualizations for understanding architecture and changes. So I wanted a visual tool to make me more effective at collaborating with my agents: visual architecture, visual change proposal, human or AI reviews, backed by git.<p>It&#x27;s still a very early tool. I&#x27;d like to add more kinds of diagrams and richer editors and make it even easier for agents to use. Would anyone else be interested in something like this? Contributions and feedback are very welcome
