# SPEC.md — Cowbull – Wordle-like game where you only get match counts

## Problem

CowBull is a word game where you have to find the hidden four-letter word. You make guesses and get back the count of exact letter matches (bulls) and partial matches (cows). It’s a bit like Wordle, but you are not told the exact letters which match, only the count of matching letters.<p>Scoring is based on the number of guesses and time used. There is a single player mode and a multi-player mode (no account required). The game source code is at <a href="https:&#x2F;&#x2F;github.com&#x2F;claceio&#x2F;cowbull" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;claceio&#x2F;cowbull</a>.<p>When I was younger, we used to play this game on paper at the back of the classroom during school and college in India. During Covid, I made this online version of the game to play with my kids.
