# ClipTurn – Rotate videos physically from File Explorer with no uploads or guesswork

## Problem

ClipTurn lets Windows users rotate videos left or right by changing the actual picture data, not just an orientation flag. Use simple right-click commands in File Explorer or open the app for previews and batch controls. The app analyzes each file, chooses a safe processing method, and only replaces the source after independent verification. It preserves codecs, audio, metadata, subtitles, and HDR when possible, and explains refusals clearly when a faithful result can't be proven. View startup
