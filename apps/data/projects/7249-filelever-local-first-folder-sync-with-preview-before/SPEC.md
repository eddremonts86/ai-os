# SPEC.md — FileLever – Local-first folder sync with preview-before-write

## Problem

Hi HN — Checkout FileLever, to sync or backup your photos, videos and more.<p>I built FileLever as a preview-first tool to review all the changes before a sync or backup runs. FileLever works with local drives, external HDD, NAS,  USB drives, SD cards, Dropbox, locally synced Google Drive.<p>Filelever started as a folder comparison&#x2F;sync tool, but I have recently added Apple Photos archival workflow to the growing list.<p>Take a look and let me know if you would like to see something more in this tool, especially from anyone here who manages large photo libraries, external drives, or backup folders.
