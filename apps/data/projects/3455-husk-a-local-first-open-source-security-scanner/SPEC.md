# Husk a Local-first, open-source, security scanner

## Problem

Seeing all of the recent supply chain attacks like the Shai-Hulud worms made us realise that it is more important than ever to have good security posture. We have tried to set up good security, but all of the existing tools bring too much friction, and they are mostly for enterprise. Husk is an open-source scanner, that helps you stay protected.
