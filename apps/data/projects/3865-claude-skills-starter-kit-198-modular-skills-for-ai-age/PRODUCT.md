# Claude Skills Starter Kit – 198 modular skills for AI agents

## Value Proposition

A starter kit of 198 modular skills that gives a Claude agent a working toolbox on day one: capabilities arrive pre-authored, uniformly packaged and individually enableable, so developers spend time on their domain instead of writing boilerplate skills. ## Jobs To Be Done

1. **Functional job** — Install a base set of skills into a Claude agent workspace.
2. **Functional job** — Browse the catalog and enable individual skills.
3. **Functional job** — Extend the kit with custom skills in the same format.
4. **Emotional job** — Start with competence: the agent is useful before any authoring.

## Success Metrics

- **Skills enabled** per workspace after install.
- **Activation share:** kit skills that fire at least once in real sessions.
- **External contributions:** pull requests or forks extending the catalog.
- **Time to value:** minutes from install to first successful skill use.

## Competitive Landscape

The post names no competitors. The category is agent-skill collections: catalogs of ready-made skills for Claude and other agent CLIs. A starter kit competes in that category on breadth, packaging quality and documentation rather than exclusivity — any skill can be copied, so the moat is curation and upkeep.
