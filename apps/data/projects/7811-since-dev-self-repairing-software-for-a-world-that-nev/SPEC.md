# SPEC.md — Since.dev – Self-repairing software for a world that never stops changing

## Problem

Since.dev is building self-repairing software for a world that never stops changing. Modern software relies on APIs, SDKs, packages, and AI models that evolve independently of your code. When a service changes, an endpoint disappears, or a model is retired, software that worked yesterday can fail without a single commit. Since.dev closes the gap between what changed outside your code and what needs to change inside it. It monitors external dependencies, assesses their impact on your repository, and prepares targeted repairs as draft pull requests. View startup
