# SPEC.md — URL Roulette – redesigned site for discovering human-submitted links

## Problem

URL Roulette allows you to submit a link and, in return, you are taken to a random site that someone else posted - no algorithm, no ranking, no AI‐generated content. It has been operating since 2017 and currently contains about 190K human‐submitted links in rotation.<p>I reconstructed the whole project over the summer and it is now back online. I launched a weekly newsletter named The Vault that recaps unusual discoveries. I developed a bookmarklet named &quot;The Boredom Button&quot; that delivers a random link from any page with a single click.<p>I would appreciate feedback on this. I am especially keen to hear from anyone who recalls the earlier version.
