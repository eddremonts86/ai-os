# Lexino - Build five-letter words with letter dominoes

## Value Proposition

Word games run on one satisfying constraint; Lexino's is letter dominoes — tiles that chain so each placement is both a word move and a spatial move. The title's promise is the pairing of two well-loved mechanics, and the product's job is to make that pairing feel inevitable: five letters, domino chains, a board that reads like a score.

**One-liner:** Build five-letter words by chaining letter dominoes.

## Target Users

| Stakeholder | Why they care |
|---|---|
| Word-game regulars | A new mechanic instead of another clone of the same grid. |
| Domino puzzle fans | Their favorite spatial loop crossed with language. |
| Daily-puzzle players | A five-minute fixed challenge with a streak. |
| Language learners | Five-letter word practice with tile constraints. |

## Jobs To Be Done

1. Place letter tiles so every chain forms a real five-letter word.
2. Get instant validation of a word, right or wrong.
3. Chase a daily best score and a streak.
4. Learn new five-letter words by failing and retrying.

## Success Metrics

- Daily puzzles completed per day.
- Session length and moves per session.
- Streak retention: the share of players who return the next day.
- Dictionary coverage complaints, the fastest signal for word-list gaps.
