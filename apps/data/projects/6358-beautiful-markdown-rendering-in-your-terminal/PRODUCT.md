_Based on source brief:_ Hey HN, I’ve been cobbling together a tool to read beautifully formatted markdown without leaving my terminal.<p>Lime renders markdown in the terminal with actual formatting - big headers, syntax highlighted code, mermaid diagrams, all drawn using Ghostty’s Kitty graphics protocol support.<p>It picks up your terminal’s native theme and you can jump between headings, pull up a table of contents to search and jump to sections of your document.<p>It’s macOS and Ghostty for now, the document lives in scroll back and we use Apple Events to ask Ghostty jump around the scroll back instead of re-rendering.
