# SPEC.md — Shortcut Express – My attempt to get the world using keyboard shortcuts

## Problem

I often see people reach for the mouse to select text or close a tab, even when they&#x27;re already typing. Most know how to copy and paste with the keyboard, but use the mouse for almost everything else.<p>I use the mouse plenty myself, but a few shortcuts have become habits. You don&#x27;t need to learn that many to find them useful. Things like moving between words or selecting a whole line come up often and are mostly universal across apps and operating systems.<p>I think most people just get used to doing things with the mouse. Learning shortcuts takes a bit of effort, and looking through a cheatsheet doesn&#x27;t help much if you don&#x27;t use what you&#x27;ve learned right away. I wanted to make something where you could practice them as you go.<p>That&#x27;s why I built Shortcut Express, a small desktop app that teaches shortcuts for everyday tasks. You practice them in a simulated text editor, browser and other familiar parts of an app.<p>Completely free and open source. Available for macOS, Windows and Linux.<p><a href="https:&#x2F;&#x2F;github.com&#x2F;chimit&#x2F;shortcut-express&#x2F;releases&#x2F;latest" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;chimit&#x2F;shortcut-express&#x2F;releases&#x2F;latest</a>
