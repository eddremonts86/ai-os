# SPEC.md — Facefork – A tree interface to AI edit photos for fun

## Problem

Hello HN.<p>I made this as a fun project with AI. No accounts, sign-ups, or any strings attached.<p>The idea: Prompt your way into having AI modifying your photos in a tree-like interface. Every edit&#x2F;prompt creates a leaf node. Share the whole tree or any single picture.<p>Uses Openrouter as a singular way to access AI image models. Bring your own key.<p>The whole project is served as a privacy-respecting static web app. No tracking. Your photos or API key never reach the web host or any third party other than Openrouter (obviously for the AI call).<p>Code is here: <a href="https:&#x2F;&#x2F;github.com&#x2F;aravindhsampath&#x2F;facefork" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;aravindhsampath&#x2F;facefork</a><p>Ask your LLM to clone, review and run it locally if you’d rather not trust&#x2F;use the hosted version.<p>Fun PRs welcome.
