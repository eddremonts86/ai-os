# SPEC.md — Concat: the open-source CapCut replacement.

## Problem

I started this project about ~3 weeks ago. Since CapCut is putting everything behind a paywall after gaining millions of installs and users, I decided to create a free and open-source version with most if not all the features.<p>Concat runs all the AI-features locally, has MCP support, has a decentralized system for assets like Filters, Effects, and Templates so users can write custom assets and share with the community (or sell them even).<p>Note: I’m self-taught dev and used Claude (Fable 5.1) heavily while building Concat.
