# SPEC.md — HyperCard to HTML Converter

## Problem

I created a converter that turns HyperCard 2.x stacks into standalone HTML so they can run in a modern browser.<p>I built it to share my own stacks from the early &#x27;90s, which have been sitting on old floppy images for 30 years.<p>It&#x27;s MIT-licensed and I&#x27;d welcome contributions - especially stacks that break the converter, since I&#x27;ve only tested it against my own. If you have old HyperCard files lying around, I&#x27;d love to hear how they fare.
