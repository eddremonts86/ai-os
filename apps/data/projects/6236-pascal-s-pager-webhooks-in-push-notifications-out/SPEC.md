# SPEC.md — Pascal's Pager – Webhooks In. Push Notifications Out

## Problem

Sometimes it just takes too long to parse a webhook from one service to another just so you can get a push notification on your iPhone.<p>Pascal&#x27;s Pager turns any JSON webhook data into a human readable push notification on your iPhone using AI.<p>It includes notification grouping and data redaction so you can select to exclude specific values from ever going to the AI.
