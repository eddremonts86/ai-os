## Value Proposition

_Based on source brief:_ I&#x27;ve been thinking about a harness for the learning use case. Current harness objective is to basically take a task and drive it to completion and minimize the need for user intervention. But if you want to learn anything, this is the almost the opposite goal. As I use agents, I&#x27;m seeing the task gets done, but I have no new capability or even intuition for solving similar tasks in the future.<p>If a student asks how to solve an equation, ideally a harness needs to have a state&#x2F;memory of learner&#x27;s past understanding, provide hints, use tools like problems&#x2F;simulations&#x2F;assessments and end the session with an evaluation to establish mastery.<p>All AI tutors I see are LLM+Prompts but I think a harness is really the right form factor for this problem. I want to see what others think and if there&#x27;s an appetite for this beyond the K12 market where adoption would be super slow.
