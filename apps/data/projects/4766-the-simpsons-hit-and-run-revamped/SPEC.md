# The Simpsons Hit and Run Revamped

## Problem

Hey folks, was browsing around for some videogame references and found a leaked Simpsons Hit n Run game source, so i took it and fixed some pretty bad issues with running the game on Windows 11 with a widescreen, including some broken audio stuff, memory leaks and security holes and forced letterbox video res.Also added some experiments that works, but they clearly need some love: DXR (Global PathTracing) and OpenXR (as for now, VR needs DXR too). I plan to add mac and linux support, and maybe OpenXR with the "original" rendererAdded a Release build for putting along the original videogame files (not included) in your pc, without compiling it by yourself, but you can do it anyway. Hope you folks enjoy it!
