## Value Proposition

MARGINAL: an open-source evidence-based governor for coding agents that requires agents to cite evidence for each action and respects per-action policies.

When I am using an AI coding agent, I want a governor that requires evidence for each action and respects per-action policies, so the agent does not silently go off-script.
