# SPEC.md — Rabbit Hole – a daily Wikipedia racing game

## Problem

Wikipedia racing used to be huge - you&#x27;d sit in a computer room at school trying to get from &quot;Cheese&quot; to &quot;World War II&quot; before your mate did.
Rabbit Hole is a wordle-style daily version that I made: one Start article, one Target article, navigate there using only Wikipedia links. New puzzle every day, fewest clicks wins. Share your results (and your route) each day with your friends and see who had the strangest path.
