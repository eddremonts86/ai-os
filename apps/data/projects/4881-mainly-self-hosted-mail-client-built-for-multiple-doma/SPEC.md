# SPEC.md — Mainly – Self-hosted mail client built for multiple domains

## Problem

Hey all,<p>I built this mail client to manage my self-hosted mail across multiple domains, and it&#x27;s ended up being my daily driver (i.e. it gets patched quick) and thought I&#x27;d share it again here.<p>I wanted something that was fast to parse visually, easy to manage &amp; customize, self-host and easily deploy, so it does all of the above.<p>I&#x27;m an inpatient fella, so it also allows you to do things like bulk onboard domains, sort addresses into folders for visual sorting, adjust custom sender images &amp; tags, has MCP integration and has a settings page for adjusting your search queries.<p>Additionally if you&#x27;re a postfix&#x2F;dovecot user, there&#x27;s a CLI script to integrate mailbox setup via the application with your server.<p>Completely free &amp; open-source, zero telemetry currently self-hostable only. Would love feedback and feature requests :~)
