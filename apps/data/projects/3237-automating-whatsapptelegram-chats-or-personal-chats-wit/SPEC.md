# Automating WhatsApp/telegram chats or personal chats with complete privacy

## Problem

Just a thought here whatsapp allows users to chat with metaai inside whatsapp giving them privacy, by using a separate container to move user query from whatsapp to ai model. And following zero retention in order to make sure none of users contents are saved in the server, this way users get complete privacy. Now what if they take it up a notch and automate users chat too. The users chats stay in there local device, and call the model provider using the same container making sure server doesn't see users data and giving them full privacy. Does this sound like something users might use on a regular basis? It does sound like a great way to relax for professionals if they have control over the context that is provided to the model.
