# trying to automate lead generation but everything automated feels spammy?i will not promote

## Tech Stack

Tools named in the source: Apollo, Seamless.AI, Clay, Prospeo. The author does not describe their own tech stack — no CRM, no sequencer, no email-sending infra is mentioned. The only stack signal is "use Prospeo to build a list, then write the email by hand".

## Architecture

Inferred from the source:

```
Prospeo (verified contacts)  ──▶  targeted list  ──▶  human writes each email  ──▶  send
                                                                          │
                                                                          └─▶  8–10% response
```

The author's framing is that "the issue isn't really the tools. It's that automated lead gen feels inherently spammy when you're blasting the same message to 500 people", so any answer that keeps volume up and personal feel down is the wrong shape.

## Milestones

The post has no milestones. If a "do the work" plan were extracted from the author's situation, the steps would be:

1. Pin down the maximum volume at which hand-written email stays economical for the team.
2. Survey the comments for a tool or workflow that beats the current 2% baseline without regressing on personal feel.
3. If none surfaces, accept that the working setup (lists + hand-written) is the answer and stop searching.

## Risks

- **Domain reputation damage is a tail risk.** A bad automated campaign can take a domain down for months; the cost of getting this wrong is asymmetric.
- **8–10% may not generalise.** The author's hybrid approach works for their ICP and offer; the same numbers may not hold for a different B2B SaaS without a SDR-equivalent founder doing the writing.
- **Tool churn.** Apollo, Seamless.AI, Clay and Prospeo are all named, which is a lot of paid seats; the cost of those tools plus the time cost of evaluation is real, and the source flags that explicitly for Clay.
