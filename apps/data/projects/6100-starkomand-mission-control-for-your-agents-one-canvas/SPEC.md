# SPEC.md — Starkomand – Mission Control for Your Agents. One Canvas

## Problem

I use Excalidraw and iTerm a lot. So I decided to build a canvas where I can launch and manage my agents using the AI subscriptions I already have.<p>I also added built-in MCP tools that let agents create diagrams, turn GitHub issues into sticky notes, and more.<p>I control most things with my voice. It can run Parakeet locally, or you can switch to GPT Realtime instead.<p>I tried to keep everything super minimal and clean.<p>I’d say it’s worth checking out.<p>Cheers!
