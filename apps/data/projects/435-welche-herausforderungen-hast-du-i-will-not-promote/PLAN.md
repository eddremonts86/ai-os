# Welche Herausforderungen hast Du? i will not promote

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Tailwind
- Postgres
- pgvector
- Resend
- Vercel

## Architecture

Next.js bilingual; Postgres with pgvector for dedup; Resend weekly digest; Vercel.

## Milestones

- German + English UI with translation toggle
- Pain-point dedup using embeddings
- Public ranked feed (sort by time lost per week)
- Developer follow-up flow

## Risks

- Dedup accuracy and German-language quality are the main risks
