# SPEC.md — I built a digital wrap tool for Tesla owners

## Problem

A while ago, I showed some friends a Tesla digital wrap I&#x27;d made in Photoshop. These wraps change how the car model looks on the Tesla screen and in the app.<p>They asked me how I&#x27;d made it, so I shared a tutorial with them. But they weren&#x27;t familiar with Photoshop and eventually gave up.<p>I also saw other Tesla owners online running into the same problem. So I built Tesla Wrap Studio using the official templates from Tesla&#x27;s GitHub repository.<p>It has a gallery of ready-made wraps you can download for free, plus an online editor for creating your own designs. You can work with your own images and text, see the results in 3D as you edit, or use AI to generate a design.
