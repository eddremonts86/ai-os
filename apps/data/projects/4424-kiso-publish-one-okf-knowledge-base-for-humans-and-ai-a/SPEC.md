# Kiso – Publish one OKF knowledge base for humans and AI agents

## Problem

I’ve been working on Kiso, an open-source publishing engine for the Open Knowledge Format (OKF) and I added an MCP server in the latest release.The idea behind it is fairly simple: I think companies will increasingly need a source of truth that can be consumed both by humans and by AI agents. Peoples and agents write the markdown files and Kiso publush a website that be consumed both by humans(html) and by AI agents(markdown).Kiso doesn't introduce a database or another proprietary knowledge store, it creates static website so you can just publih it on Github pages like I did with Google Acme example: https://oak-invest.github.io/kiso/examples/kb-acme-example/I made a “Hugo for Open Knowledge Format”.
