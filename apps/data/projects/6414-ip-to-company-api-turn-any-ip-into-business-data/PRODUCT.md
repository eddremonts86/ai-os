## Value Proposition

_Based on source brief:_ We run a marketplace and a couple of years ago we were looking for an IP to company API solution to test if we could generate additional revenues by serving high intent leads to our users. We tried many solutions, the first few that we implemented provided business data only for companies that had registered an IP, so for the vast majority of our visitors that are SMBs it didn&#x27;t work.<p>We found a couple of solutions that had great data sets and were able to unconver SMBs, but they were very expensive and required upfront payment and an annual commitment, which was not feasible for us as a small startup.<p>After many months working as a side project, we launched our own API tool that is affordable for small startups or even indie developers that would like to use an IP to company API to test if they can monetize their platform or run real-time personalization. It comes with a free tier so anybody who is interested in trying it can set up an account and test it with real data.
