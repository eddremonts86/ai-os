# SPEC.md — Locked Web – Block porn with a 72-hour removal delay and protection

## Problem

Locked Web blocks explicit content across iPhone, Android, Windows, and Mac and makes protection hard to disable. It enforces a 72-hour waiting period and a one-time unlock code for any removal or unblock request, with optional accountability notifications. The service filters every app and browser, forces SafeSearch, and supports a custom blocklist that syncs to all devices. It never records browsing history or sends reports, keeping privacy intact while the block stays on. View startup
