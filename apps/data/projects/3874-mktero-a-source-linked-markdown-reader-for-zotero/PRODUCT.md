# Mktero – a source-linked Markdown reader for Zotero

## Value Proposition

Read Markdown notes the way Zotero organizes them: every document linked back to its source item, with a rendered reading view instead of raw text. The value is the trail — no orphaned notes, no guessing which paper a note belongs to. The capture is a bare link, so the description here is the title's promise, not a verified feature list.

**One-liner:** Read your Markdown notes the way Zotero organizes them — every document linked back to its source item.

## Jobs To Be Done

1. **Functional job** — Open Markdown documents attached to Zotero items.
2. **Functional job** — Follow the link from a note to its source item and back.
3. **Functional job** — Read comfortably: rendered Markdown, not raw text.
4. **Emotional job** — Trust the trail: no orphaned notes in the library.

## Success Metrics

- **Documents opened** from Zotero per session.
- **Source-link round trips:** note to item and item to note.
- **Reader share:** Markdown attachments read through Mktero versus other editors.
- **Onboarding time:** minutes to connect a Zotero library.
