# Expense split app idea

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Node.js (Hono)
- PostgreSQL
- Stripe Connect
- Resend
- Vercel

## Architecture

Next.js; Node.js (Hono) for payment orchestration; Postgres for clubs, members, payments; Stripe Connect for payouts; Resend for reminders; Vercel.

## Milestones

- Club + member setup flow
- Stripe Connect integration with manager-not-MoR
- RSVP-gating rule engine
- Reminder emails

## Risks

- Stripe Connect onboarding complexity
- Reminder cadence annoyance
