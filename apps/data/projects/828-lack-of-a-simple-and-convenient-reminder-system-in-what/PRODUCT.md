# Lack of a simple and convenient reminder system in WhatsApp

> Auto-generated product brief. Review and refine before MVP scoping.

## Value Proposition

A WhatsApp user in the UAE sets a reminder, edits the list, and receives the nudge back in the same WhatsApp thread at the right time, without opening a separate app or remembering a new one. The framing the post supports is "reminder inside the app you already use", not "another reminder app".

**One-liner:** Reminders that arrive in the WhatsApp thread you already check.

## Target Users

| Stakeholder | Why they care |
|---|---|
| WhatsApp-heavy individuals in the UAE | Want the same app to remind them of follow-ups instead of switching to a separate reminder tool |
| Small businesses that follow up with customers in WhatsApp | Want scheduled follow-throughs to land back in the customer thread, not in a different inbox |

## Jobs To Be Done

- When something needs to come back to me, set a reminder without leaving WhatsApp.
- When a reminder fires, see it in the same thread I am already in.
- When a follow-up repeats (weekly, monthly), set it once instead of recreating it each time.

## Success Metrics

Source does not state a metric. Outcomes to validate before MVP: reminders set per user per week, share of reminders that complete (fire and are acknowledged), and repeat-reminder usage among small-business users.
