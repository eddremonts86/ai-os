# HR problem: subjective hiring and slow adaptation of new employees — design direction

Quiet, audit-friendly, and dense. The user is inside a company, not browsing a marketing surface. Sidebar navigation, a centre pane that is mostly text and structured forms, and a single accent colour for the "Submit" button and the "Sign off" button. The scorecard is a labelled list of criteria with a 1–5 row and a free-text field for each; the panel's written comments are the visible artefact, not a numeric average. The 30/60/90 plan is a table with three columns (phase, deliverable, definition of done). The dashboard is a list of new hires with a colour-coded phase indicator. No decorative charts; the user wants to read the data, not be impressed by it.
