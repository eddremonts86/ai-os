## Value Proposition

_Based on source brief:_ I built ctx to give agents a way to do a fast local search over previous session transcripts.<p>But I wanted to also give them a way to immediately surface &quot;which agent wrote this exact line of code&quot;.<p>So you can start with a commit, a file, a line, or a PR, and then deterministically surface the exact tool call that wrote it, and the full agent transcript from that session.<p>It&#x27;s really useful when you want your agents to know why code was written the way it was. It&#x27;s kind of like a &quot;super comment&quot;.<p>A normal code comment does leave some information about why code is the way it is.<p>But if you have selective access to the full original transcript, you can see everything about the code&#x27;s provenance (like what tests were run, what was the reason it was there in the first place, etc)<p>This type of information would be way too verbose for a human to find useful. But agents can just ingest this stuff and make great use of it.<p>I like to instruct the agents to delegate this type of research work to cheaper high-throughput subagents like Luna for example.
