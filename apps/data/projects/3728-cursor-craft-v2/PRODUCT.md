# Cursor Craft v2

> Product brief for the macOS cursor pack launched as v2 on ProductHunt.

## Value Proposition

A macOS user who wants a non-default cursor set can install Cursor Craft v2 — a curated, macOS-native cursor pack — and have their pointer match the aesthetic they want, with an installer that fits the OS and an update story that does not require re-buying.

**One-liner:** A rebuilt v2 of a curated Mac cursor pack that installs cleanly on current macOS.

## Target Users

| Stakeholder | Why they care |
|---|---|
| Personal macOS users | Want a non-default cursor set for aesthetic or personal-expression reasons. |
| Designers / streamers | Want the on-screen cursor to match a brand or a stream overlay. |
| Accessibility users | Want higher-contrast or larger cursors than the macOS default. |
| v1 buyers | Want a clear upgrade path to v2 without re-paying. |

The post frames the audience as individual macOS users, not enterprise or teams.

## Jobs To Be Done

1. **Functional job** — Install a curated set of macOS cursors in one step, with no manual file-shuffling.
2. **Functional job** — Cover the standard macOS cursor roles (arrow, pointer, text, busy, resize handles, etc.) so nothing falls back to the default mid-use.
3. **Emotional job** — Have the desktop feel personal without fighting macOS conventions.
4. **Social job** — Have a visible difference between v1 and v2 worth posting about, so the re-launch reads as substantive.

## Success Metrics

- **Activation:** install → cursors visible in current apps, in under 10 minutes, with no manual System Settings dance beyond what macOS requires.
- **Coverage:** every standard macOS cursor role has a v2 design; the README / product page publishes the list.
- **Update story:** v1 buyers have a documented path to v2 (free upgrade, discounted upgrade, or clear "this is a new purchase" messaging).
- **Stability:** cursors render correctly in current macOS releases, including dark / light mode.

## Pricing & Monetization

The post is a ProductHunt launch page; it does not state a price. The "v2 rebuilt" framing is consistent with a paid pack (v1 + v2 are separate purchases, or v1 buyers get a discount). Any monetization is handled on the project page, not in the post. This plan treats pricing as out of scope; the MVP must clearly publish the actual price and the upgrade terms rather than hide them.

## Competitive Landscape

- **One-off cursor packs on Gumroad / Etsy** — cheap and plentiful, but inconsistent quality and no update story.
- **macOS cursor theming apps** (Mousecape and similar) — flexible but require the user to author or import cursors themselves.
- **Iconset-themed desktop overhauls** — bundle cursors with broader icon packs; useful but heavy if the user only wants cursors.

The project's differentiator is the explicit "v2 rebuilt curated pack" framing: a focused product (cursors only) with a clear upgrade arc, rather than a one-off drop.

## Risks & Open Questions

- [ ] "Rebuilt" must mean something visible; without a concrete v1 → v2 delta, the relaunch reads as a marketing refresh.
- [ ] macOS cursor behavior is tightly coupled to OS conventions; a pack that ignores dark / light mode or the hotspot positions will read as broken.
- [ ] The update story for v1 buyers is part of the social contract; the project page must state it, not leave it implicit.
- [ ] The post does not list cursor styles or a count; the project page should publish the actual list rather than a vague "many styles."
- [ ] Cursor packs are easy to clone; the differentiator has to be ongoing curation and updates, not just the asset bundle.
