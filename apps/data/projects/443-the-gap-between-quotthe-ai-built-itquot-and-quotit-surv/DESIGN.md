# the gap between "the AI built it" and "it survived real users" is where all our bugs live — Design direction

Like a CI dashboard, not a marketing site.

- Surface: submission form + scorecard.
- Color: ink + red for failed checks, green for passed.
- Typography: monospace for check names, sans for narrative.
- No "AI confidence" score in MVP.
