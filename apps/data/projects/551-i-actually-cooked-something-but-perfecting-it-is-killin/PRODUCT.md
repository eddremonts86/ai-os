# I actually cooked something but perfecting it is killing me

> Product brief for the v2 of the niche semi-agentic video editor scoped in the source post.

## Value Proposition

A video editor in the founder's niche can use the existing plugin for assisted analysis and editing, and soon run a full auto-agent mode that integrates with three additional host programs on both Mac and Windows.

## Target Users

| Stakeholder | Why they care |
|---|---|
| Video editors in the founder's niche | Already using v1; want the auto-agent mode. |
| Video editors in adjacent niches | Would adopt if the niche coverage expands. |
| Post-production studios | Would adopt if multi-host coverage matches the workflow. |

## Jobs To Be Done

1. **Functional job** — Run the semi-agentic analysis on the niche's workflows.
2. **Functional job** — Hand off the editing to a full auto-agent when the user is ready.
3. **Functional job** — Use the plugin across 3 additional host programs.

## Success Metrics

- **Activation:** first auto-agent run completed within 7 days of install.
- **Retention:** at least 5 auto-agent runs / week per active editor.
- **Cross-host coverage:** at least 60% of v1 users adopt the additional host integrations.

## Pricing & Monetization

Free trial: 14 days, full auto-agent. Indie at $29/month: single seat, auto-agent mode, all 4 hosts. Studio at $99/seat/month: multi-user collaboration, priority support.

## Competitive Landscape

- **Runway / Descript** — general-purpose; do not specialise in the founder's niche.
- **Adobe Premiere's AI features** — first-party; cover broad workflows, not the niche.
- **Hand-built AE expressions** — what editors in the niche do today; the founder's trained model replaces this.

## Risks & Open Questions

- [ ] The founder's perfectionism on the auto-agent loop is the bottleneck; the "ship now" rule must be enforced by a feature flag.
- [ ] Native Mac and Windows builds are non-trivial; Electron would be a shortcut the founder explicitly rejects.
