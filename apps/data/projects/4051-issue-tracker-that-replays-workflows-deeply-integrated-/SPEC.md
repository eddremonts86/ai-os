# Issue tracker that replays workflows, deeply integrated with the code [video]

## Problem

Epiq is an issue tracker that is distributed, Git-native, and most interestingly, can replay state as a movie on demand. This solves one of the most difficult problems with agentic workflows - auditing and tracing in a multi agent environment. Now you can trace intent, and how it evolved while you were away.Take it for a spin:
https://ljtn.github.io/epiq
