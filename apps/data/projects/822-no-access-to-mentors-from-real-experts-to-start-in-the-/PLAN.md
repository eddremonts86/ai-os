# No access to mentors from real experts to start in the real estate field

## Tech Stack

React with TypeScript for the booking surface, TanStack Start as the Node.js API, SQLite with Drizzle ORM for mentor profiles and bookings, deployed via Coolify and Docker. Chosen because the MVP is a directory + booking flow where mentor quality is the product.

## Architecture

A web app with three surfaces: a mentor directory with niche tags and visible credentials, a single-session booking flow that takes payment or barter, and a learner view that shows the questions asked and the takeaways captured.

## Milestones

- M1 — Mentor directory with manual onboarding and niche tags (residential, commercial, RERA, NRI, etc.).
- M2 — Single-session booking flow with payment in INR and a structured intake form.
- M3 — Learner view that records the session's takeaways for the user's own notes.

## Risks

- Source is thin: scope is derived from the title alone until the original post is read.
- Vetting mentors is the harder problem than building the booking flow.
- RERA disclosures must be visible and accurate on every Indian mentor's profile.
