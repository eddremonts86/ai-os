# GPU Accelerated PDAL

## Problem

I made a fork of PDAL with GPU acceleration for NVIDIA GPUs! On common pipelines, you can get anywhere from 2 to 14x speed improvements over stock PDAL. It's a drop in replacement, just use npm i gpupdal to get it and use gpupdal for any command where you would use pdal.(PDAL is an open source library for working with point cloud data, for the uninitiated)Full source code here: https://github.com/zymazza/GPUPDAL
