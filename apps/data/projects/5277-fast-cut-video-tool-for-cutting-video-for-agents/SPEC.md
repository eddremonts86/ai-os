# SPEC.md — Fast Cut Video tool for cutting video for Agents

## Problem

Hi HN,<p>Build this tool in a couple of hours with OpenAI Codex to scratch an itch.<p>As part of my videos workflows I needed to cut the videos myself since the agent is pretty bad cutting and timing using only the transcription. But using a big app like Premiere or DaVinci Resolve was overkill so I used Astra to build an app tailored to that very task.<p>It will be useful to others with the same problem.<p>Tested only on Silicon Macs, so any feedback is welcome.<p>As part of my workflow when the agent get the video it can open the app with the video or videos loaded in the timeline for me to cut and then export the cuts in a format the agent can use and continue the workflow.
