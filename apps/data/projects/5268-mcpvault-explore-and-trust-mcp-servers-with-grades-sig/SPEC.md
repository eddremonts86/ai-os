# SPEC.md — MCPVault – Explore and trust MCP servers with grades, signals, and verification

## Problem

MCP Vault is an independent directory for Model Context Protocol servers that helps developers discover, assess, and adopt MCP services with confidence. It indexes thousands of public servers and shows live verification, quality grades, client compatibility, and maintenance signals for each listing. Creators can claim or submit their server, customize the page, and verify live connectivity to earn a badge and priority placement, all in minutes and at no cost. View startup
