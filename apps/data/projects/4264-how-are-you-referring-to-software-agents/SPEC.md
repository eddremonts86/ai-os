# How are you referring to software + agents?

## Problem

We’re increasingly building products where some tasks are solved deterministically by code, while others are handled probabilistically by agents.“Agents” doesn’t quite capture it, because agents can’t (and probably shouldn’t) do everything. “Harness” usually refers to what wraps a model and gives it the context, tools, and capabilities to act.But what do we call the whole thing: code + agents?This is becoming surprisingly verbose when trying to explain something as simple as: “we help companies build their software and their agents.”Feels like we’re due for a word here.What are you calling it?
