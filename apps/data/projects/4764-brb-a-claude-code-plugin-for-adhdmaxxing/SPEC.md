# Brb – A Claude Code plugin for adhdmaxxing

## Problem

brb is a Claude Code plugin that watches when Claude is working on a long turn. After 10 seconds (configurable), it opens a native panel offering you somewhere to go - X, Reddit, Hacker News, or anything else you want. You pick somewhere, browse for a bit, and the moment Claude finishes or needs something from you, it pings you and brings you back to the terminal.Instead of me opening X on my own and checking to see if claude is done 50 times and adhdmaxxing, brb will facilitate this in a much smoother way.
