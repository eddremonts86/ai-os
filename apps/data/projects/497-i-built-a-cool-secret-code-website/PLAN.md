# I built a cool Secret Code website!

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Web Crypto API
- PostgreSQL
- Resend
- Vercel

## Architecture

Next.js; Web Crypto API for client-side encryption; PostgreSQL for ciphertext (no plaintext); Resend for share-link notifications; Vercel.

## Milestones

- Encrypt with passkey
- Shareable ciphertext link
- Decrypt with passkey
- No-account, no-logging flow

## Risks

- Algorithm honesty
- No-logging claim verification
