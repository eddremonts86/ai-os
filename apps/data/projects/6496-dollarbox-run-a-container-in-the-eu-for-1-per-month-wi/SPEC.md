# SPEC.md — Dollarbox – Run a container in the EU for $1 per month with IPv6-only hosting

## Problem

Dollarbox offers bare-bones container hosting for €1 per month per container. You sign up, get a namespace, and deploy via a click-and-deploy flow or kubectl using a scoped kubeconfig. Each container includes 1 GB RAM and an IPv6 address, with optional pre-paid persistent storage billed per GB. There is no SLA, backups, or managed extras, and support is limited to docs and a community channel. Dollarbox targets developers who want low-cost, no-frills EU-hosted containers. View startup
