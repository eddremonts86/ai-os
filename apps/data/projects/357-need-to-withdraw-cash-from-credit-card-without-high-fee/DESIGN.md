# Need to withdraw cash from credit card without high fees — design direction

A bank-counter feel. The user is anxious about the fee; the screen should not add more anxiety. White background, soft blue accent, single-column mobile-first layout. The route comparison is a plain table: route name, total cost in euros, interest disclosure in the same wording as the issuer's terms, timeline in days. No decorative charts; the user wants to read three numbers and pick one. The booking step is a confirmation card: a single number — the total cost — in the centre, a "Confirm" button, and a smaller "Back to routes" link. Error states are written in plain language, not bank jargon. The user must not have to guess what the platform is doing.
