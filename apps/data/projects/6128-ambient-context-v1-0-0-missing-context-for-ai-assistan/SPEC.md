# SPEC.md — Ambient Context v1.0.0 (Missing context for AI assistants)

## Problem

The other week I posted a concept to use the macOS Accessibility API to capture the text on your screen into a markdown file. It seemed to be interesting with 150+ github stars.<p>I&#x27;ve done a bunch of updates and packaged them into a signed macOS app.<p>One of the biggest changes was moving away from &#x27;one context file per day&#x27; to three markdown files for apps, website, and messages.<p>I then run Andrej Karpathy&#x27;s LLM Wiki process to turn into a simple knowledge base for the day. This is then used by a smarter model to synthesise into a daily overview.<p>Let me know what you think<p>Original:
