# Kawze – Website monitoring and downtime alerts for small teams

## Problem

Kawze is a website monitoring and downtime alert service for everyone. Features aren't paywalled like other services. You can set up HTTP uptime checks, heartbeat monitoring for cron jobs, and response time tracking, then get email or SMS alerts when something breaks. It also monitors SSL certificates, DNS records, and Cloudflare cache rules to avoid surprises. Use the visitor monitor and cache warming to keep pages fast and ready. Kawze keeps pricing simple with no per-seat fees and no feature paywalls, so your whole team can stay informed. View startup
