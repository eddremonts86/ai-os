# SPEC.md — Tasku Cloud – Sync, backup, web app

## Problem

Tasku is a cli to manage your tasks in the terminal. Today we&#x27;ve added Tasku Cloud. This lets you sync and back up your tasks, as well as CRUD functionality to manage your projects. Tasku Cloud is free for individual users, with pricing coming for teams later. Install with gem install tasku and then head over to Tasku Cloud to start backups and syncing.
