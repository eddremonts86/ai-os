# Convex clients in 100 programming languages

## Problem

I work at Convex and got curious about how far agents could push one deliberately ridiculous experiment.I had them attempt to make Convex, a realtime database and compute platform, work in 100 different programming languages. That includes COBOL, Fortran, LOLCODE and even Verilog.These are experiments rather than official SDKs, but the repository includes all of the implementations if you want to poke around.I also made a video about the whole journey:
https://youtu.be/l61cLu8e2tg
