# SPEC.md — Chickadee – Free, local, open-source text-to-speech for web pages

## Problem

I wanted to listen to articles without a robotic voice or another subscription, so I built Chickadee: a free, open-source Chrome extension that runs a voice model locally.<p>It runs Kokoro-82M, an 82-million-parameter speech model, directly in your browser using WebGPU. The speech is generated on your computer. No account, API key, or subscription needed.<p>Chickadee includes:<p>• 12 voices and adjustable playback speed<p>• Sentence highlighting right on the original page<p>• Offline speech after the initial model download<p>• No account, subscription, or API key<p>Source: <a href="https:&#x2F;&#x2F;github.com&#x2F;sahilmahendrakar&#x2F;chickadee" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;sahilmahendrakar&#x2F;chickadee</a><p>I&#x27;d love to hear what you think.
