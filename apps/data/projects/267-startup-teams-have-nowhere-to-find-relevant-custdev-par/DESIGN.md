## Linear — Design System (per project)

This project's design direction is grounded in the problem's specifics:

Quiet, professional, research-tool aesthetic — neutral grey, single accent (deep teal), dense tables in admin. Inter for UI. The participant-facing Telegram bot uses system fonts and a step-by-step vetting conversation. Brand promise: honest feedback at fair pay, no gamification, no streaks.

### Design rules for this project

- Use Inter for body and headings; JetBrains Mono for code or numeric data only.
- Do not introduce new colours outside the token set above.
- Spacing scale is fixed at 4 / 12 / 24 / 48px.
- All interactive elements use 6px rounded corners; cards and modals use 8px.
- Typography weights limited to 400 / 600 — never more than two weights on a single page.
