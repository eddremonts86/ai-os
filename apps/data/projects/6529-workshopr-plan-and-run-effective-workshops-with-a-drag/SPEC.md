# SPEC.md — Workshopr – Plan and run effective workshops with a drag-and-drop agenda builder

## Problem

Workshopr is a facilitation platform that helps you design, run, and improve workshops. It combines a drag-and-drop planner with a library of over 380 exercises, 57 icebreakers, and ready-made agendas so you can build a session in minutes. Define goals, map timing automatically, and share or export live links for participants. Learn from experienced facilitators, keep interventions handy when sessions go sideways, and capture reflections afterward to turn every workshop into a repeatable craft. View startup
