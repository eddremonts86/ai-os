# Designers are losing their bearings in the era of AI — it's unclear which direction to develop in, which stack to master, and how to become a «highly valuable specialist».

## Phase 0: Scaffold

- [x] Capture the problem from ProblemHunt, including the four capabilities the author requires
- [ ] Write DESIGN.md (submission workspace, rubric score card, trajectory view)
- [ ] Write the scoring rubric for visuals, working with AI, and simplifying complex scenarios
- [ ] Decide the honest boundary of the feedback claim: rubric position and market signals, not a prediction that a direction will pay off
- [ ] Set the scenario content model with explicit version and staleness date

## Phase 1: Core

- [ ] Designer profile intake: current specialisation, domains, tools, target market
- [ ] Trajectory generator: a direction plus an ordered learning path, personalised rather than a shared curriculum
- [ ] Scenario library v1 with staleness dates and a refresh owner per scenario
- [ ] Submission flow: upload design artefacts or an agent workflow definition to object storage
- [ ] Rubric scoring service: score a submission on each axis with an explanation the user can dispute
- [ ] Human-review escalation for disputed scores, so a wrong score is correctable rather than final
- [ ] Agent-system track: scenarios requiring the design and orchestration of a multi-agent workflow, not tool operation
- [ ] Longitudinal view: score history against the chosen trajectory, including drift
- [ ] Content-freshness dashboard: days since each scenario was checked against current models and approaches
- [ ] End-to-end test: run the author's own profile through intake, one scenario, and a scored critique

## Phase 2: Deploy

- [ ] Pilot with ten designers recruited from professional communities
- [ ] Validate rubric agreement with two senior designers scoring the same submissions independently
- [ ] Test pricing in conversation with pilot users, since the source names no figure
- [ ] Review whether any pilot user committed to a direction and stayed on it after a month
