## Problem

I had a bunch of extra Fable credits, so I spent around $10k in api costs doing autoresearch loops on the top 200 github repos with frontends. The goal was to speed up the frontend &#x2F; improve the lighthouse score.<p>I distilled the wins down into a leaderboard of most common improvements, then built a wrapper that iterates through them. It ties into your claude&#x2F;cursor&#x2F;codex subscriptions, so there&#x27;s no subscription or payment - it should &quot;just work&quot; as long as you have a sub to one of those.<p>It will ask you to submit your score &#x2F; thinking trace at the end, but that&#x27;s optional. Lemme know what you think &#x2F; if it helps you out!
