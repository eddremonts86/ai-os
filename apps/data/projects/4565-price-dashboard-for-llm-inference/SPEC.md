# SPEC.md — Price Dashboard for LLM Inference

## Problem

I created a lightweight price history tracker for LLM inference across 100+ platforms.<p>Every time I run out of quota on my Claude Code and Codex, I would start trying to figure out which platform offers the most competitive pricing for DeepSeek and K3. It turns out OpenRouter is still your goto option.<p>I thought it would be interesting to track the pricing ups and downs as some historical data points. It runs every 6 hours.<p>You can also subscribe to the Atom feed. See Subscribe section.<p>Contributions are welcome.
