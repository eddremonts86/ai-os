# Language Audio Trainer – Learn languages without looking at the screen

## Problem

I recently built a language learning app with a slightly different approach. I deliberately didn't want it to be another Duolingo-like app.I think users should be able to choose what they want to learn and when.The main idea behind Language Audio Trainer is that you can simply press Play and listen to useful phrases in the background with the screen off — while walking, driving, cooking, etc. You can skip or repeat phrases, change the speech speed and number of repetitions, and choose the translation direction.There is also a flashcard mode for when you want to study more actively.I'd be interested to hear what you think about this approach to language learning.iOS: https://apps.apple.com/app/playling-language-trainer/id67619...
