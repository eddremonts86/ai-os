# Tinysandbox-JS-Runtime - JS in WASM in v8

## Problem

Tinysandbox already had a WASM-based JS runtime that worked where you could run Rust or NodeJS.This makes it so you can run isolated JS anywhere WASM runs, including the browser ([1]), Cloudflare Workers, and Convex v8 actions.It also brought the baseline WASM from 4MiB to 1MiB, and per-isolate to about 0.69MiB (nice)[1] https://tinysandbox-browser-example.pages.dev/
