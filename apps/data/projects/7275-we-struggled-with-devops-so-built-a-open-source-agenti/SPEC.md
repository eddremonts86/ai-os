## Problem

- It has 24&#x2F;7 SRE monitoring
- CI&#x2F;CD pipeline checks
- Single step deployment
- Integrated security audits for all the projects
- Sever monitoring
- Container handling<p>It is one single source to manage anything in a server. Planning to make everything more useful and robust and I&#x27;ve started using it in my day to day life now.<p>https:&#x2F;&#x2F;github.com&#x2F;putme-in&#x2F;putmein
