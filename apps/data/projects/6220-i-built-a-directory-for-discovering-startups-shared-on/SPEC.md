# SPEC.md — I built a directory for discovering startups shared on X

## Problem

I created StartupsonX to help people easily find startups that entrepreneurs are creating and discussing on X. Visitors of the website can browse and search startups based on categories like AI, developer tools, SaaS, design, fintech, marketing, and productivity. They can also submit their startups on the website. As you can see, it’s quite simple, just how I wanted it, although I am open to suggestions :D I created it because finding useful startups on X is sometimes painful, unless someones post went viral, you probably won&#x27;t see it, and there was a need for a simple platform where users can check out some cool startups without scrolling X. I’d love to hear your thoughts about the usefulness of this platform and improvements to be made.
