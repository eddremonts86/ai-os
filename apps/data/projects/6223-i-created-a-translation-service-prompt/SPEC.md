# SPEC.md — I created a translation service prompt

## Problem

I am in the process of learning European Portuguese because I moved to Portugal. I was having significant friction with Google Translate, so I started giving more and more instructions to Gemini Flash to create a powerful, low-friction experience when getting translations between English and EU Portuguese. This became a generally-powerful prompt that can serve any language combination, so I posted it to github. I haven&#x27;t tried it with any other model providers yet. Let me know what you think!
