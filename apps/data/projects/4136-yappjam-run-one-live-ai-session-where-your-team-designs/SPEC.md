# YappJam – Run one live AI session where your team designs, builds, and ships

## Problem

YappJam offers multiplayer vibe coding. While AI tools have gotten smarter, building is still solo. YappJam lets you and your mates join one live session with the same workspace, AI, and build inside a video call where ideas and inspiration flow as you work. It runs on AI agents like Claude, Codex, Gemini, or Grok, working directly in the shared workspace. Everyone can prompt, whether you're two friends hacking or a whole team shipping something. It also plugs into tools like GitHub, with MCP support, letting you go from spec to prototype in one session. View startup
