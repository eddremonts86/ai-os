# BumbleTap – Bind a key to any element, or automate the whole sequence

## Problem

The Show HN post links to https://bumbletap.com but the scraper captured only the link. From the title alone, BumbleTap lets a user bind a keyboard shortcut to any UI element or record a sequence of UI actions and play it back.

## Objective

Give non-programmers a way to bind keys to elements and automate UI sequences without scripting.

## Target Users

Power users and accessibility users who want to remap UI interactions or automate repetitive workflows in apps that do not expose keyboard shortcuts.

## MVP Scope

A desktop utility that records a UI action sequence and replays it on a hotkey, and a simpler "bind one key to one element" mode.
