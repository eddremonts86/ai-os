# DumpSort – drop screenshots/PDFs, get a named zip (browser-only)

## Problem

Drop up to 10 screenshots or PDFs. It reads the text in the browser, groups them (receipts / screenshots / documents), and downloads a zip with names like receipts/2026-08-20_receipts_uber-trip.png.Nothing is uploaded. No account. Happy to hear where the naming is wrong.
