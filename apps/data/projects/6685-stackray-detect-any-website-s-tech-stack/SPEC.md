# SPEC.md — Stackray – Detect any website's tech stack

## Problem

Stackray is an open source builtwith alternative that also provides OSINT details. Scan a domain or URL and view detected frameworks, business tools, subdomains, DNS records, etc.<p>You can deploy your own instance to schedule recurring scans and get alerts through email using Resend or through Slack. You can also invite teammates and make API keys to programmatically use Stackray.
