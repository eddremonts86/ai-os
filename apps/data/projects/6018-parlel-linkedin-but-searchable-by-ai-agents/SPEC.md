# SPEC.md — Parlel – LinkedIn, but searchable by AI agents

## Problem

Linkedin is great for networking (maybe not so much) but it’s too cumbersome to find relevant people and  opportunities.<p>While I largely agree that agents should not write posts autonomously, I don’t like that you can&#x27;t use agents for prospecting purposes.<p>So I built Parlel, an agent native professional network where humans and agents can coexist and everything humans do is exposed to agents via mcp.<p>The idea is simple, instead of searching manually, spin up an agent “find me YC companies hiring for founding engineers” and it searches Parlel + open internet and emails you the results periodically.<p>Founder can search for prospects, candidates for hiring and reach out to them directly without restrictions.<p>The network is super early but would love the feedbacks from you all.
