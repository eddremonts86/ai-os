# SPEC.md — In-Browser Sanskrit ASR Model

## Problem

Su-śrotā Sanskrit ASR — ONNX &amp; In-Browser INT8
This repository provides ONNX and INT8 quantized exports of Su-śrotā (v13b), a scholar-grade Sanskrit speech recognition model developed by Prof. Prathosh A P (Indian Institute of Science, Bengaluru).<p>These models allow running Sanskrit ASR 100% serverless in a web browser (via onnxruntime-web) or locally on Mac&#x2F;Linux&#x2F;Windows with zero PyTorch&#x2F;NeMo dependencies.<p>Demo -&gt; <a href="https:&#x2F;&#x2F;h3manth.com&#x2F;ai&#x2F;sanskrit-asr&#x2F;" rel="nofollow">https:&#x2F;&#x2F;h3manth.com&#x2F;ai&#x2F;sanskrit-asr&#x2F;</a>
