# SPEC.md — Core51 – Secure corporate messaging with exportable court-ready proof

## Problem

Core51 is a business messenger designed for daily corporate work like decisions, approvals, and sensitive discussions. It uses end-to-end encryption with on-device message protection and an untrusted server model, so only participants can read the content. Chats can't be deleted but can be frozen and organized with custom names and labels. For disputes, it offers two export modes: readable text for pre-trial steps or an encrypted package for forensic verification and court evidence. View startup
