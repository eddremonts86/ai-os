# SPEC.md — Nodlume – Plan React apps on a visual canvas and export ready project files

## Problem

Nodlume is a system design tool for React-based applications. Design the frontend—structure, navigation, wireframes—alongside the backend, data model, roles, and permissions with AI support at every step. Then generate the entire project as a Next.js web app, a Tauri desktop app, an Expo mobile app, an Ink CLI, or a browser extension. Each target has its own router and catalog. Features include live collaboration and a free tier. Early stage, so please report bugs or feature requests to support@quokkaquery.com. View startup
