# SPEC.md — FULCRUMAXE – Run an autonomous dev team in your GitHub that ships merged PRs

## Problem

FULCRUMAXE is a self-hosted autonomous software team that lives inside your GitHub workflow. It turns discussions into scoped work, opens PRs, routes code and security reviews, and merges through real gates while you decide direction. A browser-based console shows live agent activity, cost, and status. It runs on your own infrastructure and API budget, supports multiple specialized agent roles, and can scan and improve its own codebase, coordinating entirely through GitHub primitives you already use.
