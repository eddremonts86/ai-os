# Creating infographic for start-up..Please Help...I will not promote — Design direction

Editorial restraint. The poster said they "can't find any examples online," which usually means existing examples look like ad templates, not startup explainers.

- Surface: a single vertical A3 poster, 8 sections, each one card.
- Typography: a single serif for headings, sans for body, monospace for numbers (traction, MAU, MRR).
- Color: 2-color palette + one accent; everything else neutral.
- Spacing: generous; each section breathes.
- No stock photos, no clip-art mascots, no rocket emojis.
