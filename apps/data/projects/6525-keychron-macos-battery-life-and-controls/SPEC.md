# SPEC.md — Keychron macOS Battery Life and Controls

## Problem

I was struggling with getting this working as there&#x27;s no official support for reporting battery life via bluetooth and via cable. It took a bit of trial and error - but there&#x27;s a working menu bar item, a control center command, works with the desktop widget (where you&#x27;d see airpods, mouse etc), and you can control lighting with it! Hopefully it helps someone :) A lot of credit goes to claude code and Keychron for having open source firmware. This was tested with K10 Pro.
