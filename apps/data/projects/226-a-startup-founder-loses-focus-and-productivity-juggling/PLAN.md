# A startup founder loses focus and productivity juggling 5-7 tools for a single project. Existing 'all-in-one' tools are bloated, expensive, or stack-specific.

## Tech Stack

Next.js for the front-end. PostgreSQL with Prisma for the data. tRPC for the API. Redis for the cache. Stripe for the per-project pricing.

## Architecture

Project workspace → embed-able tab views for spec, decisions, meetings, tasks, money. Slack and Linear integration as a sync layer. Per-project pricing model. Per-tenant data isolation.

## Milestones

M0 — single project workspace with the 5 tabs. M1 — Slack and Linear integration. M2 — per-project pricing. M3 — 100 founders in pilot. M4 — public launch with a clear no Notion alternative stance.

## Risks

Opinionated tools can lose users when the opinion is wrong. Import from Notion or Linear will miss context. Per-project pricing may not match the way teams grow. The finance piece requires a real payment-processor integration.
