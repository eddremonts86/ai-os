# SPEC.md — Why doesn't a Cursor for Word exist?

## Problem

At this point there should be a tool that helps you easily format and style documents. I know that you can generate PDFs and DOCX files with Claude and Codex but it&#x27;s still not as user friendly as typing into a document editor and having your document get auto-formatted in there and show the changes in a diff view so that you can easily decide which changes you like. Also for text refinements right now if you use any AI tool to assist with writing it just rewrites stuff without having an easy way of visualizing the changes.
