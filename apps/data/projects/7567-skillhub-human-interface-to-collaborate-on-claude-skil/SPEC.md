# SPEC.md — SkillHub – Human interface to collaborate on Claude skills with Git sync

## Problem

SkillHub helps organizations capture and manage AI skills for Claude. Teams write, edit, and approve skills in a friendly editor while SkillHub handles versioning, reviews, and audit logs. The platform syncs approved skills to your Claude organization via a private GitHub repository it manages, preserving your ownership and source of truth. Role-based access, diffs, rollback, and repository validation keep changes safe so nontechnical experts can contribute confidently. View startup
