# I can build the SaaS. Finding the first customer is the hard part.

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- PostgreSQL
- PostHog
- Stripe
- Resend
- Vercel

## Architecture

Next.js; Postgres for check-ins + templates; PostHog for behaviour; Stripe for paid tier; Resend for weekly email; Vercel.

## Milestones

- Weekly check-in flow
- 5 common first-customer motion templates
- Public accountability log (opt-in)
- Stripe paid tier

## Risks

- Public log governance
- Paid-tier value clarity
