# SPEC.md — Permitcore – Find high-value contractors and projects from classified permit data

## Problem

Permitcore provides sales intelligence built on building permit data to help you target the right contractors and projects in your area. It classifies permits into meaningful segments, links each record to parcels, and enriches data with zoning, geocoding, roof area, and HVAC load. Sales teams can filter by metro and segment, track new filings weekly, and export enriched contractor and project data via API or bulk formats. Pricing is transparent and self-serve. View startup
