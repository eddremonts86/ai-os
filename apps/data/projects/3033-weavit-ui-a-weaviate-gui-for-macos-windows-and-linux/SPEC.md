# Weavit UI – A Weaviate GUI for macOS, Windows and Linux

## Problem

Weavit UI is a free, open-source Weaviate GUI: a cross-platform desktop client for the Weaviate vector database. Browse collections, view/edit/delete/insert objects, inspect named vectors, and run vector, keyword (BM25), and hybrid searches — then manage the instance itself
