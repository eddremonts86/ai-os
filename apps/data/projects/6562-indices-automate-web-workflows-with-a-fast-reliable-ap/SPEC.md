# SPEC.md — Indices – Automate web workflows with a fast, reliable API for any website

## Problem

Indices provides a production-grade platform to automate actions and data retrieval from any web application when official APIs are missing or limited. It learns how target sites work at the network level and exposes a reliable REST API and MCP/CLI interface to execute workflows with low latency and consistent results. It handles logins, MFA, CAPTCHA, proxies, auditing, and self-heals through cosmetic site changes so your agents and services can operate reliably at scale. No browser agents or GUI automation needed.
