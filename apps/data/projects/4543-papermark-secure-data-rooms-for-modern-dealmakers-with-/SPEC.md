# SPEC.md — Papermark – Secure data rooms for modern dealmakers with MCP and analytics

## Problem

Papermark is a secure data room platform for dealmakers, founders, and finance teams. It lets you organize documents, set granular permissions, add NDA gating and watermarking, and track page-level analytics to see what drives decisions. Teams use it for M&A, fundraising, due diligence, investor relations, and client portals. Papermark offers SSO, audit logs, IP allow-listing, end-to-end encryption, and compliance with SOC 2 Type II and ISO 27001, with the option to self-host on your own infrastructure. View startup
