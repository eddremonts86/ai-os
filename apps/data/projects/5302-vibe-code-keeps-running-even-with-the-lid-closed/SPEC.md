# SPEC.md — Vibe code keeps running, even with the lid closed

## Problem

Hello. Macs are starting to support more and more games. Now, you want to play games not only at home but also on the go. So I developed TouchNow so I can use a virtual game controller to remotely control my Mac when I&#x27;m out and about. You can even customize the controller layout for different games. It also supports internet connectivity, not just your home Wi-Fi. It&#x27;s part of the Apple Ecosystem, so it delivers maximum Apple performance, offering many features that other Remote apps can&#x27;t provide. It displays real app icons, shows real-time thumbnails of each window, and allows you to stream individual Mac windows instead of the entire screen. It can also be used as your Mac&#x27;s External Screen for touch control. Plus, it offers improved remote control, making it convenient for both gaming and everyday use.<p>Furthermore, I discovered that if you&#x27;re leaving the house while your vibe code terminal is running, TouchNow can use your iPhone as your MacBook screen. You can close your MacBook, and the terminal will continue running without interruption.<p>Free over the same Wi-Fi network. Remote access costs $2.99 per month or $19.99 per year. Any suggestions are welcome.
