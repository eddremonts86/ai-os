# I build an app that goes full screen when a solar event happens in space

## Tech Stack

Chosen for this problem:

- Swift
- SwiftUI
- macOS
- EventKit
- StoreKit
- TestFlight

## Architecture

Swift + SwiftUI macOS menu-bar app; EventKit for calendar integration; StoreKit for one-time purchase; TestFlight.

## Milestones

- Full-screen visualization on events
- Event notifications
- Live solar position
- StoreKit one-time purchase

## Risks

- Event-data accuracy
- Full-screen UX
