# SPEC.md — Localdock – Give every dev server a stable name and share it from your Mac

## Problem

Localdock is a macOS menubar app that assigns a permanent, human-readable address to each local project so your dev servers don't collide on ports and your URLs stay stable. Use the same name on localhost, across your Wi-Fi to test on a phone, or via a temporary public HTTPS link for clients and webhooks. It works without DNS or sudo, preserves hot reload, and includes tools to help coding agents avoid port conflicts. Pay once and run it on a single Mac with macOS 14+. View startup
