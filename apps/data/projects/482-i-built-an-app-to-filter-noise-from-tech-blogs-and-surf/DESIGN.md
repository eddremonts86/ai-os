# I built an app to filter noise from tech blogs and surface 6 quality engineering reads every day. How do I get more users? — Design direction

Like a printed daily paper, not a feed reader.

- Surface: daily digest as a single page.
- Color: ink + accent for "today's six."
- Typography: serif for titles, sans for summaries.
- No infinite scroll in MVP.
