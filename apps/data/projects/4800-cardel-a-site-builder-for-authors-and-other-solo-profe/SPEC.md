# Cardel, a site builder for authors and other solo professionals

## Problem

After nearly a decade in software, and recently embarking on the journey of becoming an author, I decided to create a site builder specific to authors and similar solo professionals.You can create an account, and build a full site for free. The guided mode walks you through it, the goal is for it to be that easy, but I am still working on making it better.Here is my own site that I created: https://www.orinhutchings.comNote that to publish the site (Along with some specific features) does require a subscription, but setting up the full site UI and using the editor for your own review has no paywall.
