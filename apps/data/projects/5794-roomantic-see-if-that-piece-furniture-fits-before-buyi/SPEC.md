# SPEC.md — Roomantic – See if that piece furniture fits before buying it

## Problem

Roomantic is a project I started working on earlier this year when I learned that iPhone Pro models have a LiDAR scanner and almost no practical apps that take advantage of it.<p>It uses Apple’s RoomPlan API to generate floor plans, and then allows you to paste in links to furniture and visualize if it would fit into your space.<p>Every feature is free, a subscription option exists if you want unlimited furniture placements (since those actually cost me money).<p>I tried my best to make the app beautiful, since features are now so cheap to build using AI, so any feedback would be appreciated.<p>It primarily supports U.S. retailers, but if there is any international interest, I’d be happy to build that out in the future.<p>Thanks!
