# SPEC.md — Kaden – Linux Terminal where Ctrl+C copies

## Problem

I made Kaden because every other Linux terminal lacks proper text selection.
Kaden supports Ctrl-C, A, V for copying, selecting and pasting, no more awkward three button hotkeys or fiddling with your mouse to do basic copy pasting.<p>- Contextual copy&#x2F;kill bindings to Ctrl-C.<p>- Feature rich: Inline suggestion, filter output, Themes and custom font, open URLs or files with Ctrl-Click.<p>- Local: No AI, drive, sign-in, cloud features, telemetry or network requests.<p>Kaden is a debloated fork of warp with no AI or account features.<p>I would love for you to use and give feedback on how it works (and does not) for you.<p>Github &#x2F; AppImage: <a href="https:&#x2F;&#x2F;github.com&#x2F;glitcher255&#x2F;Kaden-Terminal" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;glitcher255&#x2F;Kaden-Terminal</a><p>I&#x27;ll be here to answer any questions or feedback you have, so feel free to ask any, thank you.
