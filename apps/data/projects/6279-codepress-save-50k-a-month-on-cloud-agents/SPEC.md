# SPEC.md — CodePress – Save $50k+ a month on Cloud Agents

## Problem

Since agents have taken companies + enterprise by storm, we&#x27;ve been working on workflows to get the most out of agents that get work done.<p>Along the way, we built our own agent cloud where we ping these agents from any surface we work in, like GitHub or Slack. This lets us run tons of agents at a time, and as everyone knows, running agents like this could add up in inference cost!<p>So we built something for our agents where they can use our subscriptions that Claude Code or Codex provide us.<p>Under the hood, they&#x27;re just running the Claude Code or Codex CLI so it&#x27;s not a 3rd party harness, but their harness.<p>With this, we&#x27;ve been saving $50k &#x2F; month on inference. As long as these labs are providing these subscription deals and your company uses cloud agents, it&#x27;s a no brainer to take advantage of it.<p>This works even for teams on Claude or Codex enterprise plans.<p>We have other cool features like a centralized MCP, so you only need to connect MCP&#x27;s once and can share it with the rest of the team, automations that run on triggers or crons, apps that you can build for internal or external use, and more.<p>Check it out and let me know what you all think!
