# Halftone Stencil Cutter

## Problem

I felt in love with simple sprayed stencil making with my new laser engraver but shortly after I thought I could make it to the next level and try something more elaborate.My idea was to create cardboard stencils so I can then airbrush it onto the final medium colour by colour. This isn't anything new, there are online services that would let you to download cuts or even let it order them pre-cut.This sparked an idea of how to simplify the stencil creation process without needing to swap between different software tools - this is how the cutter had been born.It actually works, I usually need to fine tune the cutout shape so the airbrush works to my liking but otherwise it greatly improved my creative process.The UI is rather simple, it contains all the important knobs and transformations needed for the final cut.Happy cutting.
