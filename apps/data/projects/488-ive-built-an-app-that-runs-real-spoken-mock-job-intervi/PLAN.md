# I've built an app that runs real spoken mock job interviews with an AI — it researches the company first, then grills you for 30 minutes

## Tech Stack

Chosen for this problem:

- TypeScript
- Next.js
- OpenAI Realtime API
- PostgreSQL
- Stripe
- Vercel

## Architecture

Next.js; OpenAI Realtime API for voice; PostgreSQL for sessions + transcripts; Stripe for paid tier; Vercel.

## Milestones

- Realtime voice mock interview
- Post-interview scorecard
- Recording + transcript
- Stripe paid tier

## Risks

- Voice quality
- Rubric accuracy
