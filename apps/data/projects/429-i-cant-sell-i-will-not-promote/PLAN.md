# I can’t sell. (I will not promote)

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Node.js API (Hono)
- PostgreSQL
- Stripe
- Loom embed
- Vercel

## Architecture

Next.js front-end with native video upload; Hono API; Postgres for submissions, critiques, and refund flags; Stripe for single-tier payment; Vercel deploy.

## Milestones

- Critique rubric (ICP, opening, objection, close) with one annotated example
- Video upload + async reviewer dashboard
- Public pricing page and refund policy
- Public sample critique (anonymised) to convert skeptics

## Risks

- Reviewer capacity is the bottleneck
- AI-assisted annotation reduces it
- Quality variance is the core product risk
