# SPEC.md — renderit.now – Make search bots see your React site by serving rendered HTML

## Problem

renderit.now intercepts bot traffic to your JavaScript-rendered site and serves fully rendered HTML so search engines, AI crawlers, and social preview bots can index and display your real content. It detects over 30 bot patterns, excludes API and asset routes, and caches renders for fast repeats. Setup takes minutes with LiteSpeed, Nginx, or Cloudflare rules. A live auto-generated sitemap keeps new routes discoverable without rebuilds or code changes. View startup
