# Are chat room software still relevant? — Design direction

Like a forum thread inside a website, not a chat app.

- Surface: widget that looks like part of the host site.
- Color: inheritable from host site; default ink + accent.
- Typography: sans, host-site inherit where possible.
- No "online now" pulse animation in MVP.
