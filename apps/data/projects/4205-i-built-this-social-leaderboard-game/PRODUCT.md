# I built this social leaderboard game

## Value Proposition

King of the World is a low-stakes social leaderboard game: climb the leaderboard, hold the title, share it with friends — and nothing in the real world changes.

**One-liner:** An online social leaderboard game where the title is purely in-game.

## Target Users

Casual players who like leaderboard-style competition without stakes. Adjacent: streamers or communities that want a small, silly shared game to rally around.

## Jobs To Be Done

- When I have a few minutes, I want to play and climb a leaderboard so I can brag in chat.
- When I hold the top spot, I want a shareable handle or badge so my friends see it.

## Success Metrics

- Daily active players.
- Average session length.
- Share rate of the title or top rank.
- Week-over-week retention (qualitative; source gives no target).
