# Veault – Digital legacy management with secure inheritance and zero-knowledge

## Problem

Veault redefines digital legacy planning with client-side zero-knowledge encryption and a fail-safe inheritance system. Unlike typical password managers, Veault never holds your key. It uses a controlled unlock process where trusted contacts use secret keys to request access, triggering alert emails so you can cancel if needed. Vaults unlock only after a custom waiting period or manual death certificate verification. Local encrypted backups guarantee lifelong control. View startup
