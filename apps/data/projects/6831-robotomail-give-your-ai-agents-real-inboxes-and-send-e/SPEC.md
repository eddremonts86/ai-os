# SPEC.md — Robotomail – Give your AI agents real inboxes and send email with one API call

## Problem

Robotomail provides email for AI agents, giving each agent a real mailbox it can create, send from, receive to, and manage via API. Provision mailboxes with one POST request, send and receive messages, and handle threading automatically. Get real-time inbound through webhooks or SSE, attach files, and control usage per mailbox. Use your own domains with auto-configured DKIM, SPF, and DMARC. Robotomail helps you build agents that communicate reliably over email. View startup
