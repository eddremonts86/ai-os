# LumoTray for Mac

## Problem

Hi all,My app LumoTray is now available for macOS.LumoTray is a multi-monitor wallpaper, screensaver and lockscreen manager with a custom menu builder and hot-corners implementation.I've been developing the Windows version for a few years now and decided to try and figure out if something similar could be done on macOS.It turned out much better than what I was expecting and has achieved pretty much feature and UI parity with the Windows version.That being said, since I do not have access to many Macs (or different macOS versions) it's being released as Beta until there is more real world usage.More info and download links for both the macOS and Windows versions at https://lumotray.comAny feedback is welcome.Cheers!
