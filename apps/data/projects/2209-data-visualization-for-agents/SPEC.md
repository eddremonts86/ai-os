# Data Visualization for Agents

## Problem

I was looking for a good "journalistic" data visualization library for a project I am working on, and didnt really come across anything I liked (both aesthetically and that are easy for agents to work with). So I created OpenChart. It is inspired by/extends the vega-lite spec, which makes it easy for agents to write chart spec rather than svg or d3.js code.
