# Mdpreview – Markdown in the terminal (images, diagrams, big headings)

## Problem

Well, everyday I spend more and more time fully inside the terminal and I noticed the time I spend reading markdown now greatly overshadows the time I spend actually writing it, so this helps render markdown nicely. Mermaid diagrams to an extent look good and somewhat understandable without launching any other app. I tried glow and it felt like end of the day I was still looking at markdown like # titles or *effects* didn't hit the same. Inline images and mermaid diagrams are actually what I wanted the most. Zero dependencies typescript. Gets the job done.
