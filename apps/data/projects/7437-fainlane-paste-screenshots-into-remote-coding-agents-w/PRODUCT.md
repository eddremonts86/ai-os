## Value Proposition

_Based on source brief:_ Hi all,<p>I run all my CLI coding agents in a remote cloud VM and not being able to paste screenshots has been my only annoyance.<p>So I built this small (2mb) native macOS app that helps me paste screenshots into remote coding agents with Ctrl+V, same as pasting images on coding agents running on my local mac. The app automatically detects the remote host based on the focused window and uploads the image over SSH inside the `~&#x2F;.cache&#x2F;fainlane&#x2F;uploads&#x2F;` directory on the remote machine and then inserts the path at cursor.<p>The app supports Ghostty, iTerm2, and Apple Terminal. Works even if you have multiple remote hosts you connect to. And works if you use tmux as well.
