# VoxelTV – Turn music videos into interactive 3D voxel sculptures

## Problem

The app renders each video as a voxel grid in Three.js. Color is sampled from the current frame, while height is produced from Depth Anything-generated depth maps. I recently added the ability to create your own local versions, all within the browser.
