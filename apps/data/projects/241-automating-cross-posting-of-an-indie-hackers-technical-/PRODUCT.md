# Automating cross-posting of an indie hacker's technical content across multiple platforms (Twitter, LinkedIn, Product Hunt) while adhering to each platform's best practices

> Auto-generated product brief. Review and refine before MVP scoping.

## Value Proposition

Eliminates the manual reformatting step that makes cross-posting inconsistent, while keeping the human in the loop on the final per-platform version.

## Target Users

Indie hackers and small technical founders; solo content creators who already maintain a canonical writing surface and want to be on three platforms without reformatting three times.

## Jobs To Be Done

When I finish a canonical draft, I want three per-platform previews with the right length and tone so that I can approve and schedule in one click. When posts go live, I want to see engagement per platform next to the canonical draft so I know which variant worked.

## Success Metrics

Drafts posted to 3+ platforms per active user per month. Engagement-rate lift vs. manually posted baselines. Subscription retention at 90 days.

## Competitive Landscape

Buffer and Hootsuite are general social schedulers, not variant-aware. Repurpose.io is video-focused. Typefully is Twitter-first. None of the existing tools understand platform-specific technical-content conventions, per the source.

## Risks & Open Questions

Each platform's API changes regularly and can break connectors. Twitter/X API pricing changes are a known risk. Engagement pull-back varies in availability per platform. Need to validate willingness-to-pay with 15 indie-hacker interviews — source does not state a price.
