# A Free Open Source End to End Encrypted Journal Web App

## Problem
 Github: https://github.com/MrSheerluck/smbl-journal I built a free, open-source, end-to-end encrypted text journal. The goal is to make journaling as simple as possible. The entire text-based journal is free with no limits. Entries are encrypted on the client before being stored, so the server never receives plaintext journal content. The project is open source and available on GitHub. Built with SvelteKit, Rust, and SQLite. submitted by /u/lazyhawk20 [link] [comments]
