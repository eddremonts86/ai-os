# SPEC.md — SuperOpt – Linux Shortcuts on Mac

## Problem

so as a long time Fedora user I just got a macbook for work. while it&#x27;s so much faster than my old Fedora-based work laptop, it&#x27;s also running macOS... which I really don&#x27;t want to learn or get used to. i tried a Fedora VM on the Macbook and even then the modifier keys are still garbled.<p>my friends kept telling i&#x27;d simply get used to macOS but i&#x27;d like to stick to what i know.. instead of spending some time adjusting to macOS, i spent a few days with an LLM to create a program which uses macOS accessibility features as well as private APIs to make the experience as close to my Fedora computer as possible.<p>it adds some features like a close button in mission control, &quot;snap assist&quot; from windows 10, and the option to remap various keyboard shortcuts to their &quot;normal&quot; equivalents (e.g., ctrl+c -&gt; cmd+c). of course everything can be turned individually on or off.<p>i feel a lot more confident using macOS now after this now that the majority of my muscle memory can transfer over to macos.<p>since the code is written by AI it&#x27;s licensed under WTFPL.
