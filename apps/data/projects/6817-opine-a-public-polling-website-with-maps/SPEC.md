# SPEC.md — Opine, a public polling website with maps

## Problem

Hi, I made Opine (<a href="https:&#x2F;&#x2F;opinepolls.com" rel="nofollow">https:&#x2F;&#x2F;opinepolls.com</a>), a poll-based social media site. Each post is a public poll asking users their opinion on something, anonymously, so no user sees any other user&#x27;s information, but you can freely browse other polls. Private polls can also be made.<p>The only information actually stored is the email, from Google sign in, and an approximate location for the map feature, if you enable it. This allows you to see a world map of votes, what opinions are present in what places.<p>The intent is to catalog the world&#x27;s opinions, organizing people&#x27;s public thoughts so they&#x27;re easy to sift through. This data can be extremely valuable, whether it&#x27;s political polling, information about people&#x27;s preferences, trends over time, and so on. Many people could benefit from this, and it&#x27;s meant as a public service, to lift the veil on what people think about any topic, at any time. Easier political polling is just one obvious application of this.<p>Please try it out and give any feedback, thoughts, questions, and so on, here or within the profile section on the website, which is fully anonymous. Thanks.
