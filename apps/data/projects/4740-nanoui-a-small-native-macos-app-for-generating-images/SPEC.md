# NanoUI – A small native macOS app for generating images with OpenRouter

## Problem

I needed to generate a large number of images using Nano Banana 2, using reference images. Playing with OpenRouter I discovered that most image gen models use similar params, so I made something I could use in a pinch to work with said params, without bothering with OpenRouter's playground. I use it nearly every day.
