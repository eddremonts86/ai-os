# PostMCP/ai – Run social media with an AI agent that drafts, schedules, and posts

## Problem

PostMCP/ai automates your social media with an AI agent that writes, schedules, and publishes posts across LinkedIn, X, Instagram, Facebook, Threads, Bluesky, and YouTube Shorts. It adapts content for each network, keeps a shared calendar for teams, and lets you approve every draft. PostMCP also offers an open-source social media MCP server so Claude, ChatGPT, Cursor, and other MCP clients can call typed tools to publish. Connect your AI or use the built-in agent to manage everything in one place. View startup
