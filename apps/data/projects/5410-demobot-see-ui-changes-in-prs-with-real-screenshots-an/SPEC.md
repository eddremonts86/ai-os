# SPEC.md — DemoBot – See UI changes in PRs with real screenshots and AI summaries

## Problem

DemoBot captures visual changes from your code and posts them directly in pull request comments. It runs the branch, detects your framework, builds the app, and takes real screenshots of affected views so reviewers can verify UI changes without local checkout or hunting through preview deploys. It also generates a plain-English summary of what changed and why. Teams integrate via a GitHub App, support secrets and test logins, and pay based on demo runs per month. View startup
