# SPEC.md — An open source PDF Reader with annotation, notes, SRS, Linking support

## Problem

A calm, local-first desktop PDF reader designed to make sure you remember what you read. You can link notes across files and group notes&#x2F;annotations into a larger Markdown note, which can be linked with others.<p>The Releases are only for Windows, but you can use the code to build for any system Tauri Supports (Linux- Debian or macOS).<p>It&#x27;s fast and small in size and has first-class support for annotations and note-taking.<p>You can check out the code here<p><a href="https:&#x2F;&#x2F;github.com&#x2F;roshanmishra86&#x2F;Mereth-Reader" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;roshanmishra86&#x2F;Mereth-Reader</a><p>Looking forward to your feedback.
