## Value Proposition

_Based on source brief:_ You find a UI you like, screenshot it, and lose it in a folder you'll never open again. Stele fixes that. One keystroke captures any element, page, or screen recording, including live DOM and CSS, not just pixels. Every capture lands on your canvas, grouped into stacks and organized by project, so you can find it later by what you remember, not the file name. Copy any element as production React code or an editable Figma layer, with real typography, spacing, and colors intact.
