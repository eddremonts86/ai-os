# Smolknight – a CLI chess puzzle game (best played on Desktop)

## Problem

Wrote a little chess CLI puzzle game because I wanted to practice some Python.You play as a knight, capture all the enemy pawns before they reach the end of the chessboard. Includes 15 levels.Feel free to submit your own levels to the repo via PRs, you can use solver.py to check if your levels are solvable before submitting :)Repo here: https://github.com/hengmhs/smolknight
