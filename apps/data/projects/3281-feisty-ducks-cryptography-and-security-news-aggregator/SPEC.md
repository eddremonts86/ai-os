# Feisty Duck's Cryptography and Security News Aggregator

## Problem

I thought this was something the Hacker News audience would appreciate; it's an aggregator of computer and security news. We initially built it for ourselves (we have a monthly newsletter, for 12+ years), but realised that others might like it as well.Although we collect a wide range of news, we currently promote to the front page what's on-topic for our audience, which is (currently) Web PKI, TLS, post-quantum cryptography, some cryptography, some security, and some privacy. We generally don't do vulnerabilities at all (although those will inevitably be picked for in the "all news" section).I've made an attempt to amplify the original voices in the security space, rather than just collecting what's already news. There's more work to be done in that direction.
