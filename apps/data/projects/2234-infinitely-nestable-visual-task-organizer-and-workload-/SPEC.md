# Infinitely nestable visual task organizer and workload simulator

## Problem

I built ProjectZen because ordinary task managers often show what needs doing, but not whether the accumulated workload is realistic.The homepage includes a working demo, no login required. I’d especially value feedback on whether the workload view makes sense without explanation and whether it would change how you plan a real project.This project is personally interesting to me because, as a product manager for many years, I never found a tool with the usability and visual workload simulation I knew was possible. Without the latter, I felt disoriented and more helpless when it came to being pressured into scope creep. ProjectZen was created as a side project using Angular, Django, Google App Engine, Google Cloud SQL, and Firebase Authentication.The tool includes Infinite nesting for breaking down projects and tasks (inspired by tools like Workflowy and Dynalist)
 Displaying items in kanban boards
 Visualization of tasks based on size and simulation of overall workload over time

Also included are Regex filtering by any field in any view
 Custom statuses and types
 Storypoints (from Scrum) for task sizing
 Ability to run sprints
 Ability to display items in a flat list, rather than in a tree
 Sharing

Next planned updates include more types of progress visualizations.Feel free to play with it, no login required. If you'd like to save your work, though, you're welcome to create a free account. Would love any feedback!
