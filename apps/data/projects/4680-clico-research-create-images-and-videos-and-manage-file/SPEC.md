# SPEC.md — Clico – Research, create images and videos, and manage files in one chat

## Problem

Clico is an AI studio that unifies deep web research, file Q&A, and image and video generation in a single conversational workspace. Use Clico Web in your browser, Clico Desktop across Mac apps, or the Chrome Extension beside any page. Choose models like Claude, GPT, Gemini, Kimi, or Grok, bring in references, and generate finished images and MP4 videos without watermarks. Keep citations with answers, resume saved conversations, and share snapshots securely when you are ready. View startup
