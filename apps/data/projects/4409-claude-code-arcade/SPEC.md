# Claude Code Arcade

## Problem

This week-end, I wondered if we could add a little fun animation in Claude Code CLI's status line on macOS, based on the LLM current work. First I created a fish tank, then a safari scene, only using emojis. Being an 80's kid, I challenged Fable 5 to add a Ms Pac-Man, with good sprites. I used a hack to control Ms Pac-Man using F1/F2 keys.
I finished the week-end adding a WOPR simulator to the project, just because it's the best movie ever.
Arcade games on ONE line are not the best ones, I know. ;-D
