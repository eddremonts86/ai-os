# SPEC.md — Baselineplan – Upload your MS Project file for instant risk and schedule insights

## Problem

BaselinePlan audits MS Project schedules in minutes with a 15-indicator health score, schedule statistics, an S-curve with earned value, Monte Carlo forecast dates, and a revision comparison showing exactly which tasks slipped. It also generates daily, weekly, and monthly target sheets ready to send to your crew. You can export to Excel and PDF, and files are never stored. Built for construction planners.
