# SPEC.md — Ivx/AI Chat, AI client that doesn't track you (with a better GUI imo)

## Problem

Since ChatGPT started pushing ads and somehow my instagram reels started getting more and more related to what I talked with ChatGPT, I decided to get rid of it for good. So I built ivx&#x2F;ai Chat. I know there are many many chat interfaces out there already but this one is special. It is built exactly around what I personally prefer. It is a lightweight, browser-based client with no backend, no accounts, no analytics, and zero telemetry with apps for almost all platforms. Talks directly to the AI provider or connects with your locally running inference. It also supports WebLLM for local in-browser inference in case you dont wanna use any other provider but also supports cloud providers like OpenAI, Anthropic, and OpenRouter. I hope you like it.
