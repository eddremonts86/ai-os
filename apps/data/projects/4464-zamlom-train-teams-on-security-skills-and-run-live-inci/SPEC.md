# SPEC.md — Zamlom – Train teams on security skills and run live incident response tabletops

## Problem

Zamlom is a role-based security training and incident response readiness platform. It offers structured lessons, flashcards, and assessments across leadership, architecture, GRC, and operations. It tests skills under pressure with live, multiplayer tabletop exercises where each role has its own view. The platform generates a professional After-Action Report mapped to NIST CSF, designed for auditors, insurers, and boards. It closes the loop by mapping gaps to targeted modules so teams can remediate, rerun scenarios, and measure improvement. View startup
