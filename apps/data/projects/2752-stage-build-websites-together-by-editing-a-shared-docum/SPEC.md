# Stage – Build websites together by editing a shared document

## Problem

Hi everyone,Stage is a collaborative website builder where teams create websites together by editing a shared document.AI website builders today are chat-based, which makes collaboration difficult because the workflow is inherently single-threaded.Stage takes a different approach: 1. Anyone on the team can contribute ideas to a shared document at any time.
 2. An AI agent detects the intent behind those changes and updates the website.
 3. The website updates live.

Because everything happens in one shared document, the full context is preserved and easy to share.We are launching later this week with limited capacity. If you’re interested, please reserve your spot here:
https://buildonstage.comCheers!
