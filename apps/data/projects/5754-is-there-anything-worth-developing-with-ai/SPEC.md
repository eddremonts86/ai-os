# SPEC.md — Is there anything worth developing with AI?

## Problem

It seems to me that humans already developed everything that makes money, multiple times.<p>Apps? The market is full, hundreds of apps are doing the same. Another hundreds are country specific (and doing the same). Bike rental clones, Uber clones, whatever clones, if the business model works it&#x27;s already cloned.<p>Games? 12000 games released on Steam this year so far. No one cares. GTA6 is the game for 2026.<p>Is there anything out there we cannot do (and already done) without AI?<p>Is there a killer AI app?<p>I&#x27;m talking about coding specifically, because it seems like this is the easiest thing to do with AI. The training data is excellent (all the training data code is tested and working, thanks humans). The output of the AI can be automatically tested for validity (working or not). I don&#x27;t think anyone going to write code from now on (for what?).<p>Corporations can develop new features quickly for existing products. Great, but is there anything missing? From fb, gmail, whatever? Are these software so complicated it&#x27;s impossible to maintain anymore by humans? The tech debt is so big a new feature takes months to develop? Or what? Even if this is the case, and the AI can do everything it in a day, what is the killer feature?<p>It will be useful for testing security, we need AI to protect against the AI.<p>And it&#x27;s going to replace a lot of programmers, especially at big companies. The lazy programmers automate everything, but this time it went too far :)
