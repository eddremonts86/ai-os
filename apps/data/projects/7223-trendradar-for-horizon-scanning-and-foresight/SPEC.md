# SPEC.md — Trendradar for Horizon Scanning and Foresight

## Problem

This is an update to our old Trendradar (<a href="https:&#x2F;&#x2F;news.ycombinator.com&#x2F;item?id=45332076">https:&#x2F;&#x2F;news.ycombinator.com&#x2F;item?id=45332076</a>)<p># What changed
* This trend radar focuses on trends in general (not only technological trends as the previous ones)
* This trend radar splits individual trends into granular signals, and each signal is based one 3 or more individual sources.<p>The idea is to provide companies a data-driven scan of the environment (horizon scanning) as a basis. With this basis, they can derive conclusions about the direction of a market.<p>Although V2, there are still a few issues to fix, especially around self-reporting &amp; PR sources which tend to overrepresent trends. Furthermore, we are planning on expanding it to include a more diverse set of sources (especially patents &amp; GitHub), to catch changes even earlier.<p>Ironically, AI has made web scraping per se cheaper, but overall it seems that the total costs (as a consequence of complexity and the sheer number of content) have increased.
