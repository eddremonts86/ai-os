# SPEC.md — ZenTabTimer, an HTML timer where browser favicon is the timer

## Problem

An HTML page where the favicon is a circle that drains over timer. Great for pomodoro work sessions while keeping the timer in view. Like a zen sand timer for your browser.<p>I found myself using the timer built into google search all the time to keep on track during a work session, but as soon as I had too many tabs, I&#x27;d end up clicking the tab all the time to see how much time was left. Plus, the countdown change movement would become visually distracting. Here, the circle &quot;drains&quot; without visible or distracting movement.<p>Vibe coding used to be a fun term for a low stakes thing made for fun, but these days it&#x27;s a become a loaded term as real companies pressure their devs to vibe!<p>So, let&#x27;s call this thing &quot;Vibegentically Agenteered&quot; to mean what vibe coding used to mean, a quickly made low stakes thing just for fun.
