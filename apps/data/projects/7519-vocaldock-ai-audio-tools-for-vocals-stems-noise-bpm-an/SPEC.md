# SPEC.md — VocalDock – AI audio tools for vocals, stems, noise, BPM, and key

## Problem

VocalDock is a browser-based audio toolkit for musicians, podcasters, and content creators. It lets you remove vocals, create karaoke tracks, split songs into up to six stems, reduce background noise, shift pitch, and detect musical key and BPM. Free browser tools run locally without an account, and cloud AI processing is available through daily credits, credit packs, or memberships. View startup
