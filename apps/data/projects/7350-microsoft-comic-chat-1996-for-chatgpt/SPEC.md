# SPEC.md — Microsoft Comic Chat (1996) for ChatGPT

## Problem

I love good old Microsoft Comic Chat (1996-1998). Since the source is now public and archived, I made a fork and added support for ChatGPT, so that you can have a comic chat with GPT itself. The LLM is instructed to emote using the UI convention.
