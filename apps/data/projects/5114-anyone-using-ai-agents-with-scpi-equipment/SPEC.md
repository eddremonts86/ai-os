# Anyone using AI agents with SCPI equipment?

## Problem

I upgraded my home hobby electronics bench with equipment using SCPI (Standard Commands for Programmable Instruments). Looking for others' experiences and suggestions.So far I was able to:- produce a desktop graph of multimeter V DC readings (a kind of slow oscilloscope) using a LABLOOT LB1041 DMM- set a scope up to decode UART, using a SIGLENT SDS814X- set output voltage on a bench power supply, using an OWON SPS6051- load arbitrary waveforms into a signal generator using a OWON DGE2045.What are others using SCPI for and are you allowing coding agents to write code to do useful things?What other SCPI equipment would you suggest for a modest home electronics bench?I also use AI agents to evaluate USB-connected devices like UARTs and MCUs (in conjunction with signal generation and scope/meter readings)
