# Are you still using AI code autocomplete?

## Problem

The poster has noticed rapid progress in coding assistants and is wondering whether AI-powered autocomplete (Cursor Tab, Copilot, or similar) is still an important part of developers' workflows. They personally never built the habit because by the time they had access to decent autocomplete tools, agent-style assistants (Cline, Augment) were already common. They ask whether other developers still use autocomplete, whether they use it less when they also use agents, and whether the two complement each other.

## Objective

There is no product idea in the post. The poster is running a community survey.

## Target Users

Software developers who use AI coding tools, especially those balancing autocomplete-style tools with agent-style ones.

No MVP.
