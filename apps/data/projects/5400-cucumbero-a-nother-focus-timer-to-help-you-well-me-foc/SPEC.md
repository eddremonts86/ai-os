# SPEC.md — Cucumbero, a(nother) focus timer to help you (well, me) focus (maybe)

## Problem

I&#x27;ve made myself a timer + website blocker chrome extension to help me focus. Yes, there are dozens of extensions like this already, yet somehow none of them did quite what I wanted.<p>Which is: you set a timer, and the extension blocks your chosen websites, while you&#x27;re trying to finally get some work done. Not much more to it.<p>To list some features of any note:<p><pre><code>  - it&#x27;s kinda neat
  - it doesn&#x27;t redirect your tabs, so they&#x27;re intact when your session ends
  - the timer can count down from a set time or up until you stop it
  - entirely local, no external requests whatsoever
  - mostly vibe-coded (but I&#x27;ve read through the code, and so can you)
</code></pre>
