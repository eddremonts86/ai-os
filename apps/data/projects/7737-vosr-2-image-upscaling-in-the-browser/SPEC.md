# SPEC.md — VOSR 2 image upscaling, in the browser

## Problem

Hey everyone, I’ve been interested in AI image upscaling for years, but running these models locally usually requires setting up complicated development environments. I used AI to port VOSR2 to WebGPU so anyone can run it directly in their browser.<p>You’ll still need a fairly powerful machine, such as a modern Mac, but the results are comparable to Topaz, and it’s free. I’d love to hear what you think.
