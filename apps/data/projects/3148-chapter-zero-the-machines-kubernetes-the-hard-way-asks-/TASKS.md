# Chapter Zero – the machines Kubernetes The Hard Way asks you to bring

## Phase 0: Scaffold

- [ ] Create the repo and the infrastructure module layout
- [ ] Read the tutorial's prerequisites and write them down as a machine spec
- [ ] Choose and document the first provisioning target
- [ ] Write SPEC.md, PRODUCT.md, PLAN.md, TASKS.md, DESIGN.md

## Phase 1: Core

- [ ] Implement provisioning of the full machine set on the first target
- [ ] Configure OS, SSH access, and inter-node networking as the tutorial assumes
- [ ] Implement status and destroy commands
- [ ] Warn about cost before creating anything billable
- [ ] Verify a learner can reach chapter one from a clean machine

## Phase 2: Deploy

- [ ] Create the GitHub repo
- [ ] Deploy to Coolify (or chosen host)
- [ ] Verify in production
