# ChatGPT Linux GUI version updates redownload all files, require 1.4GB download

## Problem

Not limited to this update (26.825.31414 to 26.831.21537). Every update seems to redownload all files. The program is 1.4GB large and a version update requires a 1.4GB download. It really stands out among the Linux upgrade experience. Had to remove the program because I regularly install updates from shitty wifi and this just means I would not install updates anymore. Not even Flatpaks have that much bloat. Yes, it does more under the hood, but still I want to shout "It's 1.4GB for a text interface!" Everyone else is capable of optimizing.Interesting data point that reflects really poorly on the org.
