# SPEC.md — A FOSS Expense Splitter

## Problem

Hey! Showing off a project I&#x27;ve been working on for a while. Peanut Split is an expense splitter where the room is a link. There are no accounts; people just join via the link.<p>Source: <a href="https:&#x2F;&#x2F;github.com&#x2F;peanutprotocol&#x2F;peanutsplit" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;peanutprotocol&#x2F;peanutsplit</a> (AGPL-3.0).<p>One fun bit is that not only are 162 currencies supported, but you can also add any imaginary currency; gold doubloons, friendpoints, whatever you want, and just peg it with an exchange rate to a &quot;real&quot; currency (or not).<p>Also, receipt scanning works and other Splitwise &quot;premium&quot; features are fully supported.<p>It&#x27;s free, open source, and as little telemetry as so on as possible.
