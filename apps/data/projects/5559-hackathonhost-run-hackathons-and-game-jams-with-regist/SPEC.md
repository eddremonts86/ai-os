# SPEC.md — HackathonHost – Run hackathons and game jams with registration, teams, and scoring

## Problem

HackathonHost is an all-in-one platform to run hackathons and game jams from start to finish. It includes registration, team building, live control, project submissions, judging and scoring, certificates, and post-event analytics in one dashboard. Use it online, in person, or hybrid with white-label branding, tenant-isolated data, email broadcasts, live polls, website embeds, and an API. Manage the event from one screen, schedule reveals, and export reports and QR-verified certificates—all for one flat price with no subscriptions. View startup
