## Value Proposition

_Based on source brief:_ Hi everyone, this is my first original post on Hacker News. I’d like to share my thoughts on the next generation of AI agents. I believe these agents will operate autonomously over long periods. While current chat interfaces are designed for conversation, the interfaces for next-gen agents should focus on delegation; they will be capable of gathering environmental data, interpreting requirements, and working continuously toward a goal for days or even a month. That is why I ported <i>prove2me</i> and built the <i>build2me</i> project. My inspiration came from <i>prove2me</i>, which uses Lean to run multi-agent systems for long-term mathematical proof verification—a process requiring extensive exploration and prolonged task execution. I believe this same logic applies to software development and long-term self-iterating projects. I invite you to try it out and please feel free to reach out with any feedback. Thank you.
