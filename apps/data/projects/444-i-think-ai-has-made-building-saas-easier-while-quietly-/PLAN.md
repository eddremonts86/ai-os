# I think AI has made building SaaS easier while quietly making one part of SaaS much more dangerous

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- PostgreSQL
- PostHog
- Stripe
- Resend
- Vercel

## Architecture

Next.js; Postgres for reviews + variants; PostHog for outcome analytics; Stripe for paid tier; Resend for digest; Vercel.

## Milestones

- URL submission + trust-signal scorecard
- Public examples library (anonymised)
- A/B-test variant generator
- Outcome survey (self-reported conversion lift)

## Risks

- Scoring model accuracy
- A/B test sample-size feasibility
