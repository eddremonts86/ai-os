# Serendipity – rediscover the web one interesting page at a time

## Problem

Random URLs are easy. Useful serendipity is hard.I've built a free (no ads) app for both Android and iOS for users who want to swipe/surf between websites they otherwise would never have thought to find, both with some randomness and some light personalisation to keep the experience satiating. Users can also search the live web for uncovered topics - the results of which are then (subject to moderation) added to the corpus. It's a bit like StumbleUpon was but for the modern user.Curious if any of you have any thoughts on how much personalisation you can add before serendipity becomes just another recommendation bubble?Please do try it out and let me know your thoughts!
