# SPEC.md — MCP server manager: KyttoMCP – in beta

## Problem

Hi everyone, I’m interested in MCP configs and came up with an idea for an app that could manage MCP servers across clients like Cursor, Claude Code, Codex, Claude Desktop, and VS Code, keeping everything in one place. So, I built KyttoMCP—an app that tracks your configs and centralizes everything. It includes features like &quot;MCP Doctor,&quot; profiles, and more. It supports macOS and Windows (though please note the builds are unsigned).
