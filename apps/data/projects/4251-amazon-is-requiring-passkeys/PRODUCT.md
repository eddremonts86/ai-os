They can't be phished or stolen, and they're supported by most modern smartphones, tablets, and operating systems.Set up your passkey, as it will be required for every login after that date. If you haven’t set one up yet, you’ll be prompted to enroll. Your password will remain on file as a backup recovery option but won’t be available for logging in.We recommend setting up passkeys on at least two devices in case a device is unavailable. Passkeys sync automatically across devices signed into the same Apple ID, Google account, or Microsoft account.*To set up a passkey:*1. Log in to Amazon Business.
2. Go to *Login & Security*.
3. Select *Set up* beside *Passkeys*.
4. Follow the on-screen instructions to complete set up (takes less than two minutes).Users with shared Amazon accounts must register any additional people accessing the account as secondary users to create their own passkey and log in separately.*To add secondary users:*1. Go to *Settings* and select *User Permissions*.
2. Select the desired account for the new user.
3. Enter the user’s contact information and select *Send invitation*. The secondary user will need a brand-new email address that has not been used on any Amazon account before.
4. Repeat for all new users that need to be added.
5. Request new users to follow the email instructions.*Note*: Only users who have registered as secondary users will be able to set up a passkey and log in separately to the shared account.
