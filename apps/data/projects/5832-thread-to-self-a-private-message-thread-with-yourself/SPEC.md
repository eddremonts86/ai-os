# SPEC.md — Thread to Self – a private message thread with yourself

## Problem

Hello,<p>Thread to Self was created because I wanted a way to capture thoughts (random or otherwise) in a single stream. I didn&#x27;t want to have to deal with folders or tags or any other type of organization took that would make it become an admin heavy burden.<p>This is a naive IOS and local first, so no accounts, no metrics and no mining. It&#x27;s you and your thoughts.<p>I did use AI to build this but it was not a 1 day endeavor. To get her took months of building and refining.<p>I use it daily (in fact multiple times a day) but want to see if other people would actually want to use it. Where are the pain points that make the app to simplistic.<p>Thanks,
