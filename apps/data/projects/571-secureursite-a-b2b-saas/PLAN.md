# SecureUrSite — black-box SaaS security testing for B2B

## Tech Stack

Service-first, not software-first. Tooling: Kali/BlackArch on the consultant's side; a Notion or PDF deliverable template; a Stripe billing layer; a basic landing page.

## Architecture

Consultancy pipeline: (1) lead capture, (2) scoping call, (3) manual pentest, (4) report + remediation call. The SaaS wrapper (if it ever ships) is a self-service scope-questionnaire + report-template generator.

## Milestones

M1: complete one pro-bono pentest for a friendly B2B SaaS to build a public deliverable. M2: land first paid engagement. M3: 3 paid engagements. M4: evaluate whether to productise.

## Risks

Risk: lead flow is slow without a brand. Risk: report quality varies; one bad report kills the funnel.
