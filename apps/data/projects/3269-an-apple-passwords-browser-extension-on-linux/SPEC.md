# An Apple Passwords browser extension on Linux

## Problem

Goal was to use Apple Passwords from my Linux desktop (with a browser extension to autofill passwords). Combines existing public reverse engineering attempts. Also pulls TOTP codes from the keychain and HideMyEmail aliases from iCloud API. It also does NOT write new passwords back to iCloud (yet).
