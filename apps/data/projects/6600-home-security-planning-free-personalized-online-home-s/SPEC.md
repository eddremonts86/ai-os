# SPEC.md — Home Security Planning – Free personalized online home security assessment and upgrade plan

## Problem

Home Security Planning is a free, fully online home security assessment that helps households identify practical security weaknesses and decide what to improve first. Answer questions about your home and existing security measures to receive a personalized Home Security Score, prioritized upgrade recommendations, and an instant PDF report. Where available, HSP also provides official local burglary statistics for additional context. No account, personal information, or payment is required. View startup
