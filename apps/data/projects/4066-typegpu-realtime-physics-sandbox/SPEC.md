# TypeGPU Realtime Physics Sandbox

## Problem

Inspired by Konrad Reczko Depth-aware light injection in TypeGPU - the sandbox showcases realtime PBF fluid simulation, Eulerian smoke, and multi-source light simulation on photos, videos, and live webcam.Scene gravity is inferred from the depth maps surface normals so tilted scenes should simulate fluid motion accurately.It also includes a few fun features like hand tracking and a WIP cup interior detection so you can fill up cups/glasses that appear in live video.
