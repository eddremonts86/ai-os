## Value Proposition

_Based on source brief:_ hop started from a frustration: every project I work on accumulates browser tabs, while tmux sessions can only contain terminals. This really started getting out of hand once coding agents took hold, as more things are now going on at the same time.<p>On top of that, I&#x27;ve started doing more work in sandboxed environments, and tmux isn&#x27;t great at managing sessions across different environments - it wants a tmux server everywhere.<p>So hop moves the project session up to the window-manager level: terminals and GUI apps live together, while shells and the editor can run locally, in a container, or over SSH.
