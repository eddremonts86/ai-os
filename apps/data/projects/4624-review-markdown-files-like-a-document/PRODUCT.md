## Value Proposition

_Based on source brief:_ Markdown has become the preferred format for documentation and authoring skills across many teams. Yet, our tools to review markdown files haven’t really kept up. Reviewing changes to a markdown file still requires you switch back and forth between the preview and source mode. The preview mode is easier to read but does not show diffs or comments, whereas the source mode allows diffs and comments but is not easy to read.
