# SPEC.md — Stirfry, a small Ruby web framework mixing it up

## Problem

Stirfry is a ruby webframe work with JSX-like templating, easy routing, and minimal magic! It is made for mixing everything all together with htmx so there is almost no line between frontend or backend!<p>Is this good design? No. 
Is it a good idea? Also no. 
Does it support Rack-based middleware? Yes!
Should you use it? Almost definitely not.
Is it fun? To me it is!<p>Shout out to <a href="https:&#x2F;&#x2F;github.com&#x2F;patbenatar&#x2F;rbexy" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;patbenatar&#x2F;rbexy</a> that I used as a starting point to write a RBX parser.<p>Shout out to <a href="https:&#x2F;&#x2F;github.com&#x2F;sinatra&#x2F;sinatra" rel="nofollow">https:&#x2F;&#x2F;github.com&#x2F;sinatra&#x2F;sinatra</a> for being my fave and basically the template for this project.<p>Shout out to Rack as well because it&#x27;s still a great&#x2F;fun interface after all of these years!
