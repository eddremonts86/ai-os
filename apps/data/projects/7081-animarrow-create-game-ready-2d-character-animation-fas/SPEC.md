# SPEC.md — Animarrow – Create game-ready 2D character animation faster and iterate freely

## Problem

Animarrow is a 2D animation engine built for game creators. It lets you rig artwork with bones, weights, IK, and constraints, then animate on a single timeline with keyframes, easing, and onion skin. The editor’s preview matches the runtime, so you can iterate quickly and ship with confidence. Export one file that plays natively in Unity, Godot, React, and the browser, powered by a Rust core. Plans include Starter, Indie, and Studio to support teams from prototype to production. View startup
