# Intelix – AI agent that investigates and resolves production incidents

## Problem

Hi HN,I built Intelix, an AI incident-response agent for engineering teams.When a production incident happens, Intelix investigates it instead of simply notifying an engineer.It gathers evidence across PagerDuty, Datadog, GitHub and Kubernetes, identifies and ranks possible root causes, validates whether a recovery action is safe, and then executes the recovery.I built an interactive live demo where you can watch the agent investigate and resolve a simulated production incident in real time.Try it here:https://intelix.devThis is an early version of Intelix, currently focused on automated incident investigation and recovery.
