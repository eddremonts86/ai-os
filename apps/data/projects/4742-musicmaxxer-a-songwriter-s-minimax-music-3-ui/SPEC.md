# MusicMaxxer – a songwriter's MiniMax Music 3 UI

## Problem

Tired of paying for Suno, I made this local desktop app for Windows and macOS to generate songs through MiniMax's hosted Music API (free for up to 3 songs/minute!). I wanted something tailor-made for a songwriter, so I implemented some QoL features to make rhyme-making easier.
