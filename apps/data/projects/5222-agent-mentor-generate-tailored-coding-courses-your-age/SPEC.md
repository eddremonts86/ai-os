# Agent Mentor – Generate tailored coding courses your agent writes and you own

## Problem

Agent Mentor is an AI course generator that helps your coding agent write complete, source-cited lessons and exercises as plain Markdown files on your machine. You provide a brief and topic, and it plans multi-lesson courses, grades practice locally, and renders them in a local Next.js reader. It supports in-place Q&A, optional web research, audio, and publishing, using your own API key or hosted credits. You keep the files and can edit, back up, and share them. View startup
