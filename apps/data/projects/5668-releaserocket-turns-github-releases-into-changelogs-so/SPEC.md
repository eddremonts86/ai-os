# SPEC.md — ReleaseRocket – Turns GitHub releases into changelogs, social posts, emails, and more

## Problem

ReleaseRocket turns your GitHub releases into a changelog, social posts, email, blog posts, and more, written by AI and reviewed by you. Push a tag and it drafts release notes from the commit messages between tags, then adapts them for channels like X and LinkedIn through Typefully or Post Bridge, email via your own Resend account, Slack, Discord, an MDX blog export, and a hosted changelog page. We use it ourselves: releaserocket.io/changelog/releaserocket. View startup
