## Problem

AI Agents Listing is a curated directory for the agentic ecosystem. It helps you discover AI agents, MCP servers, and drop-in agent skills, ranking them by real engagement rather than ads. You can browse popular categories, view leaderboards, and submit your own tools to get discovered.
