# I built my portfolio site with an AI website builder in an afternoon, here's what broke and what held up

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- MDX
- PostgreSQL
- Resend
- Vercel

## Architecture

Next.js; MDX for content; PostgreSQL for portfolio data; Resend for notifications; Vercel.

## Milestones

- Single-page template
- AI-assisted content filling
- One-click subdomain deploy
- "What worked / what didn't" review page

## Risks

- AI output quality
- Template uniqueness
