# SPEC.md — Edit or Die (an experimental "text editor")

## Problem

I’ve been thinking a lot recently about what it means to write with AI, but really about what it means to edit with AI, since from my experience that’s really where I’ve been using LLMs.<p>Before LLMs, there were apps like The Most Dangerous Writing App and Write or Die, which helped combat writer’s block by deleting your progress if you stopped typing. Even then, the amount of words written was not the point, it was how the process led to better writing.<p>This is an exploration of that, for LLMs. Given a starting prompt, and with an LLM constantly writing, can you edit (reason?) fast enough to stay ahead of what it spits out? What does it mean to be done when it’s possible for the machine to never stop?
