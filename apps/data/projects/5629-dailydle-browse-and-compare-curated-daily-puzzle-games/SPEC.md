# SPEC.md — dailydle – Browse and compare curated daily puzzle games with clear source links

## Problem

dailydle is a curated directory for daily and short repeatable games across words, geography, music, movies, sports, logic, trivia, and more. It highlights clear rules, reliable source links, and easy-to-understand gameplay so you can quickly find what to play each day. Explore editor picks, popular collections, and new submissions, or submit your own game for review. Save favorites by signing in and build a daily rotation that fits your interests. View startup
