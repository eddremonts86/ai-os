# Built a free platform to learn to code — the problem was never "no free content," it's "nobody tells you what to learn first"

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- MDX
- PostgreSQL
- Resend
- Vercel

## Architecture

Next.js; MDX for lesson content; PostgreSQL for progress; Resend for reminders; Vercel.

## Milestones

- Curated project tracks
- "Why I quit" story library
- Lightweight streak (opt-in)
- Reminder flow

## Risks

- Streak counter governance
- Track curation
