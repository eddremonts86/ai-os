# SiteTweak – a browser extension to modify any website

## Problem

I've made an extension that works in the sidebar and lets you modify any website with AI.I tried to make it feel like using Cursor or Codex. You can talk to it in a chat panel to refine the modification, ask a question, or request automation.If you'd like, you can plug in your own key from OpenRouter or any other OpenAI-compatible service.What I and early users actually use it for:- Real-time claude.ai limits and a live usage chart, without having to open settings- A draggable magnifying glass for YouTube videos- Rearranging and hiding page elements for a cleaner view on stream- A one-click ZIP download button when the site only allowed saving files one by one
