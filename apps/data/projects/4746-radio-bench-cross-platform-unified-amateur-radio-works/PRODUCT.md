## Value Proposition

_Based on source brief:_ I built a cross platform amateur radio program using the egui framework. It was originally built as quite frankly I got annoyed with having so many different programs installed to listen to and send radio signals. If you have a cheap SDR radio dongle like the RTL based ones or even better an AirspyHF+ Discovery laying around then give radio bench a try. Bonus points if you are a licensed ham and have a transceiver.The key idea behind the software is to have a much more realistic and calm workspace for making contacts. The all singing, all dancing programs with the windows 95 style ui are just not that fun to use. You get used to them, and even tolerate them, but there is a better way! And to that end I tried to something about it. I adopted the "if I were going to live on a mountain-top and could only have one radio program, what would it be" approach. I think I heard that from Rick Rubin, or some other video short. FSK mode (for FT8/FT4) is currently in the pipeline.You can run the program for 14 days free, there is no account/email. Honestly if you send some feedback I can extend your trial. If the feedback is good I'll sling you a free copy. I'm not even sure the pricing is about right.
