# SPEC.md — Control Claude Code from your Tesla's screen

## Problem

You can now screen share your Mac and control Claude Code on the Tesla screen.<p>I found myself sometimes running Claude Code on my laptop in the passenger seat and thought &quot;I would love to see it on my screen also&quot;. This lead to me building this Tesla screen sharing thing, that works super nicely with Claude Code. There is also a button on the screen to toggle voice mode so that you can control it with voice.<p>Would be super to get people to test it and tell me if it is useful or not. I use it every day, but definitely biased!<p>Happy to answer any questions!
