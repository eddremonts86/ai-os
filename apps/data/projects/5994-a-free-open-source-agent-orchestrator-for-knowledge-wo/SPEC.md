# SPEC.md — A free, open-source agent orchestrator for knowledge work

## Problem

I am happy to share something I have been working on for the past few months: an open-source agent orchestrator for knowledge work, built on Hermes Agent.<p>For context, I started building verso on my own free time as a learning exercise a few months ago. It&#x27;s now become the set up that I use for work every day and it has significantly increased my productivity. I wanted to have an easy and intuitive way to interact with Hermes Agent without having to use the CLI. Then one thing led to another.<p>It connects to the apps you already use, builds context autonomously, learns and grows with you, and most importantly, it really gets things done!<p>I use it every day to keep track of projects and tasks, prepare for meetings, write docs, find prospects, and put together commercial proposals. It brings together information from the sources you connect so the agent has context about what you’re working on, without you having to explain everything from scratch.<p>Verso will continue to be a personal project but I am proud of what I&#x27;ve done and I am eager to share it with the world. If you end up giving it a go, I&#x27;d love to hear from you!
