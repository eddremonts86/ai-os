# Sloppie – Agentic development environment for Linux

## Problem

Hi! In my own development work I have noticed I less and less reach for Emacs and rather need the combo of a coding agent + git diff viewer + a stack of code-review comments to handle later.There's a lot of apps that do more or less that but mostly for Mac, heavy churn and too much features I don't need, arranged in a way that makes for a noisy and distracting interface.So, I wrote my own. Not as a throw-away project but one to actually use daily. It's tailored for my own needs and probably not useful as-is for others, but maybe something for inspiration or customization.
