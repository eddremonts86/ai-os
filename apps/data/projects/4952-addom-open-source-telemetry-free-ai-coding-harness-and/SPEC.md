# Addom – Open-source, telemetry-free AI coding harness and editor

## Problem

I started this project six months ago.
While the market already had decent AI harnesses, none of them felt like they had what I actually needed.What began as a simple, minimalist tool quickly grew into one of my most ambitious projects.
I started with basic tool calling and streaming, but that wasn't enough. I wanted a full-fledged application where I could build my own apps and that required testing and maturity.I needed local artifacts where I could easily revert unwanted file changes, an editor to view and modify project files directly, a memory tab to review past prompts and code changes, and a practical agent system with skills so I wouldn't have to rewrite files just to add roles.Nothing about ADDOM is perfect, but it's a solid foundation. It's been a lot of fun to play with. It’s MIT-licensed, open to contributions, and I hope you like it.Thanks for taking the time to read this. Happy coding!
Check it out at https://www.addom.app/
