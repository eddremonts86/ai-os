## Value Proposition

_Based on source brief:_ JT from uncSoft here, dev of cyberWriter and Anubis-OSSThere is an annoying as heck bug in macOS when you are using a secondary monitor and have other macs around - if you have push through edge to control another mac on and/or screen connect active, often times your mouse will get eaten and disappear completely. Especially if you have a VM running in one of them using Screen Connect. Hotkey or Shake the mouse to recover your cursor. This utility was built in 5% Swift, 5% Shell, and 90% FrustrationMousetrapped is free and open source and the release is notarized and signed.Just shake your mouse (wth adjustable sensitivity) or hit ⌃⌥⌘Mand your mouse will pop up on your selected or primary display by default - even if it is currently controlling another mac.If you are on a trackpad only setup and using edge-push to control another mac, use the keyboard shortcut to reclaim your cursor (shake works if you are using a mouse, trackpad only HID inputs eat the shake detection on a remote mac)Readme and Release here
https://github.com/uncSoft/MousetrappedHomebrew Install - brew install --cask uncSoft/mousetrapped/mousetrapped

Or Download and run the signed releasehttps://github.com/uncSoft/Mousetrapped/releases/latestSo goshdang annoying to lose your mouse into the etherhttps://imgur.com/VsqPylwhttps://imgur.com/TZyZr9H
