# Mindspark

## Problem

This could be the only mind map you would be looking for.
MindSpark is an open-source mind-mapping app you actually own with no accounts, no paywalls, no feature gates, and no usage limits. Selfhost it in one command, run it free in the browser with every map saved to your own private GitHub repo, or add one small Cloudflare Worker to unlock real-time sharing and collaboration
