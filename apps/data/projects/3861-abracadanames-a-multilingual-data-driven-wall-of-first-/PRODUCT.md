# AbracadaNames – a multilingual, data-driven wall of first names

## Value Proposition

Browse names the way you would browse a wall, not a database. AbracadaNames is a multilingual, data-driven wall of first names with infinite scrolling and search by country and origin, built so exploring feels effortless and you actually have a chance of finding a name you like — original or classical.

**One-liner:** A multilingual, data-driven wall of first names for effortless exploration.

## Target Users

| Stakeholder | Why they care |
|---|---|
| Parents-to-be | Explore first names across countries without database fatigue. |
| Users burned by other name sites | An experience explicitly designed against the paginated-database feel. |
| Origin-curious browsers | Search by country and origin to explore naming cultures. |

## Jobs To Be Done

1. **Functional job** — Scroll an infinite wall of first names without pagination breaks.
2. **Functional job** — Search and filter names by country, origin and other dimensions.
3. **Functional job** — Discover both original and classical names in one browsing experience.
4. **Emotional job** — Feel a real chance of finding a name that fits, rather than sifting a list.

## Success Metrics

- **Scroll depth:** names viewed per session and share of sessions passing a meaningful scroll threshold.
- **Search usage:** share of sessions using country or origin filters.
- **Return visits:** users coming back for more browsing sessions.
- **Feedback quality:** the author explicitly asks for feedback; actionable comments per visitor are the early signal.

## Competitive Landscape

The post does not name competitors beyond the general category it reacts against: existing name websites that feel like long paginated databases. ## Risks & Open Questions

- [ ] The differentiation is experiential; a wall UI can still feel like noise if density or performance is off.
- [ ] Dataset quality and multilingual coverage are unstated; gaps in countries and origins will show immediately.
- [ ] Infinite scrolling at large dataset sizes needs careful rendering to stay pleasant.
- [ ] The author says the site will keep evolving; scope creep risks eroding the focused experience.
- [ ] No monetization path is stated; the sustainability of a feedback-driven side project is open.
