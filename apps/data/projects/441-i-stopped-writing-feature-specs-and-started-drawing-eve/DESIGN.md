# I stopped writing feature specs and started drawing every feature as a flowchart first. Way less wasted code. — Design direction

Like an Excalidraw whiteboard for product specs, not a Jira clone.

- Surface: canvas on the left, Markdown on the right.
- Color: ink + one accent for unsynced edits.
- Typography: monospace for node IDs, sans for spec text.
- No "task" or "ticket" semantics in MVP.
