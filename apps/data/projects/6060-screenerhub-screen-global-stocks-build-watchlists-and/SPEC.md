# SPEC.md — ScreenerHub – Screen global stocks, build watchlists, and automate portfolio monitoring

## Problem

ScreenerHub helps investors discover, track, and validate stocks with powerful screening, watchlists, and automated monitoring. Filter 13,000+ stocks across 80+ metrics and decades of history, then save candidates to focused lists to compare performance over time. Run automated ongoing checks to see which holdings still match your strategy and get email alerts when stocks drift. Built-in AI features translate strategies into filters or challenge your own screener logic to refine ideas faster without jumping between tools. View startup
