# Chaosword – A Crossword?

## Problem

Three crosswords a day. The same puzzles for everyone. Morning (5x5), Evening (7x7), and Midnight (11x11). Fresh grids, fill, and clues each evening. The grids are always solvable. The clues range from direct definitions to playful wordplay.Sort of a rogue-like crossword with daily dials randomly selected for each game that adjust the layout, clues, connected-ness, etc.
