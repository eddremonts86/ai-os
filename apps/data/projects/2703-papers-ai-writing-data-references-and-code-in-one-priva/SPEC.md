# Papers AI – Writing, data, references, and code in one private research workspace

## Problem

Papers AI is an offline-first research workspace that combines writing, data, references, and code into a single flow. It lets you draft, analyze, and run notebooks alongside documents, with optional AI that understands your project context. It runs LaTeX, Typst, MyST, and Jupyter in your browser, and supports local-first storage with optional cloud sync for collaboration. Work online or offline, track changes, comment, and integrate local AI models so you control what reads your work. View startup
