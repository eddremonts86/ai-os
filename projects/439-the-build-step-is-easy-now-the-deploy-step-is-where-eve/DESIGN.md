# The build step is easy now, the deploy step is where every small tool dies — Design direction

CLI-first, no marketing surface. The tool itself is the design.

- CLI: minimal, subcommands `init`, `up`, `down`, `logs`.
- Docs site: dark theme, monospace, no marketing hero.
- Errors: actionable, point to a single doc URL.
- No SaaS upsell in MVP output.
