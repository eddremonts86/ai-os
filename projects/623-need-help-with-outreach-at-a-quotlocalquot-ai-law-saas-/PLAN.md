# Need help with outreach at a "local" AI law SaaS

## Tech Stack

- **The AI-lawyer platform:** the founder's existing codebase (out of scope for this plan).
- **Outreach playbook:** Next.js + TypeScript + Tailwind CSS for the founder dashboard.
- **Storage:** Supabase (auth, the weekly tracker, the per-channel playbook).
- **Payments:** Stripe.

## Architecture

Single web app for the outreach playbook + the weekly tracker. The AI-lawyer platform is the founder's existing codebase and is not modified by this plan.

## Milestones

1. **M0 — Spec freeze.** SPEC.md + DESIGN.md + the 5-channel outreach playbook. End of week 1.
2. **M1 — Weekly outreach tracker.** End of week 3.
3. **M2 — 1:1 outreach coaching intake (Pro tier).** End of week 5.
4. **M3 — Stripe paywall.** End of week 7.

## Risks

- **Legal-services advertising regulations** — paid acquisition is excluded in the EU; the playbook must respect this.
- **Lawyer-association rules** — outreach must respect the rules in each jurisdiction.
