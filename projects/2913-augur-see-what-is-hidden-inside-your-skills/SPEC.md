# Augur – see what is hidden inside your skills

## Problem

Augur is the tool I built having a bit of fear not knowing if something is hidden in the skills I am using more and more.It parses different types of files, works from command line as from the simple TUI, can scan a file or whole folder, and can create clean copies of files with hidden characters or watermarks.It supports jpeg, png, webp, gif, pdf, docsx/xlsx/pptx + ODF, any valid UTF-8, binary, and other formats.It has 13 detectors and 40 finding kinds, decodes four types of schemes, two types of cleaners.Free and open source - Apache 2.0
