# Spent 3 months building the wrong version of my app before realizing the actual insight

> Auto-enriched product brief.

## Value Proposition

A pre-build "wrong-version detector" that helps founders figure out what the actual user problem is before coding, with a restart playbook.

## Target Users

- Solo founders who built the wrong version of their app
- First-time founders with a finished MVP that no one uses
- Indie hackers iterating on a side project that stalled

## Jobs To Be Done

When I am about to build (or rebuild) my app, I want a pre-build detector that surfaces hidden assumptions, so I do not spend 3 months building the wrong version again.

## Success Metrics

- At least 100 questionnaires in pilot
- Self-reported "I changed what I built" rate above 40%
