# My wife and I built a Mac app that turns your screenshots into actions - explain an error and create an issue, add events to Calendar, save contacts and more.

## Tech Stack

Chosen for this problem:

- Swift
- SwiftUI
- CoreData
- AppleScript
- StoreKit
- TestFlight

## Architecture

Swift + SwiftUI menu-bar app; CoreData for screenshots + actions; AppleScript for system integration; StoreKit for paid tier; TestFlight.

## Milestones

- Screenshot capture + system shortcut
- On-device OCR
- Top-3 action suggestions
- StoreKit paid tier

## Risks

- OCR accuracy
- Action suggestion quality
