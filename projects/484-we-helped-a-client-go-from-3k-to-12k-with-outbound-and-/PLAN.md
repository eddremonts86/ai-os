# We helped a client go from $3K to $12K with outbound and now we’re looking for 5 agency owners to help for free

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Python (FastAPI)
- PostgreSQL
- Stripe
- Resend
- Vercel

## Architecture

Next.js dashboard; FastAPI for outbound orchestration; Postgres for ICP, prospects, replies; Stripe for billing; Resend for transactional; Vercel.

## Milestones

- ICP builder
- Prospect-list builder
- Outreach sequencer
- Reply inbox + tagging

- Reply-rate variance
- Pilot expectations
