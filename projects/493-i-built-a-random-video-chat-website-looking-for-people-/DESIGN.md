# I built a random video chat website — looking for people to test it — Design direction

Like a quiet video booth, not a chat roulette.

- Surface: single video window + topic prompt + report button.
- Color: ink + accent for "new match."
- Typography: sans for UI.
- No emojis. No "next" spam button.
