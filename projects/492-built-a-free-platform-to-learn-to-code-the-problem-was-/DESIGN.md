# Built a free platform to learn to code — the problem was never "no free content," it's "nobody tells you what to learn first" — Design direction

Like a quiet study room, not a gamified learning site.

- Surface: lesson + story + project panel.
- Color: ink + accent for "restart."
- Typography: serif for stories, sans for lessons.
- No leaderboards in MVP.
