# Built a free platform to learn to code — the problem was never "no free content," it's "nobody tells you what to learn first"

> Auto-enriched product brief.

## Value Proposition

A free platform to learn to code that addresses the "I gave up" problem rather than the "no free content" problem, with curated project tracks and restart stories.

## Target Users

- Adults who started learning to code and quit
- Bootcamp / self-taught learners who stalled after the first course
- Career switchers who want a low-pressure restart

## Jobs To Be Done

When I have given up on learning to code and want to restart, I want a free platform that names the "I gave up" reasons and offers a project-based restart path, so I am not told to "just stick with it."

## Success Metrics

- At least 200 restart stories in 90 days
- Median 30-day retention above 25%
