# Open-Source Framer Alternative

## Problem

Hi,I've been working for two years on a design-oriented website builder which i've just released.Popular website builders like Framer and Webflow are great products, but their vendor-lock in and lack of proper code export is something that I found too non-user centric. You are paying rent on your own website.So i've decided to create Revyme, which is open source, self-hostable where you can design and export your code in Next.JS to host it anywhere.
