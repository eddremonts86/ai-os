# Automated submission of utility meter readings to multiple management companies — design direction

Quiet, trustworthy, and unbranded. The user is here to do a chore, not to feel delighted. White background, neutral grey for body text, single accent colour for the "Submit" button and the confirmation checkmark. The intake screen is a vertical list of meters with the previous reading to the left and the new reading to the right; the user types the new number and the system validates it against the previous reading. The dashboard is a table of months, each row a list of portals with a green tick or a red cross, and a click-through to the captured confirmation page. The reminder SMS is a single sentence in Russian with a deep link.
