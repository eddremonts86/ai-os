# What did you learn when you stopped following tutorials?

## Problem

When I was working with Python, I noticed something interesting. If we build a Python project using a YouTube tutorial, it seems straightforward. But when I sit down with my laptop and code editor, I usually discover what I actually don’t understand.We will not learn logic by copying someone else’s code. I learned logic by figuring things out myself.
