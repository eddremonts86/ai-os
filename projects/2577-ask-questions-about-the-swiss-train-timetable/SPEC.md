# Ask questions about the Swiss train timetable

## Problem

I use the SBB website and app every day to find my Swiss train journeys, but even with the touch tiles I find it cumbersome to use, especially for extra filters like avoiding bus or finding trains with space for bicycles.So I built https://fragplan.ch/ to describe a train journey in natural language, and translate it into an SBB timetable request. I'm especially happy about the many settings one can make on SBB.The name is a play on the words "fragen" (to ask) and "Fahrplan" (timetable).I wish there was something like this directly in the SBB app...
