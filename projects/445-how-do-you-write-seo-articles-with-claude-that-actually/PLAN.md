# How do you write SEO articles with Claude that actually rank?

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Anthropic API
- PostgreSQL
- Meilisearch
- Stripe
- Vercel

## Architecture

Next.js; Anthropic API for drafting; Postgres for articles + briefs + citations; Meilisearch for entity + SERP index; Stripe for paid tier; Vercel.

## Milestones

- Keyword → content brief flow
- Claude draft with strict citation rubric
- Editor view with citation + entity coverage highlighting
- Outcome tracking (publish + rank)

## Risks

- Citation enforcement
- SERP freshness
