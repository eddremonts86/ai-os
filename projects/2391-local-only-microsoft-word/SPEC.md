# Local-Only Microsoft Word?

## Problem

Let's say I bought a new PC. New, so running Windows 11. And let's say I wanted Microsoft Word, and thought that Libre Office wasn't good enough because reasons. And let's say I wanted Microsoft Word that lived on my PC, not off in the cloud somewhere - something I could still use even without an internet connection, and where all my files were local and stayed local.What was the last version of Word that was local-only? Can one still buy a new copy? If so, from where?
