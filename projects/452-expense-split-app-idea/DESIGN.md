# Expense split app idea — Design direction

Like a treasurer's ledger, not a banking app.

- Surface: club dashboard + member table.
- Color: ink + accent for unpaid.
- Typography: monospace for amounts, sans for names.
- No "invest" or "savings" features in MVP.
