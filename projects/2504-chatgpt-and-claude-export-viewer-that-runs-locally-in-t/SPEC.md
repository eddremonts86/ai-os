# ChatGPT and Claude export viewer that runs locally in the browser

## Problem

I regularly export my chats from ChatGPT and Claude as backup. There are times I wanted to quickly see what is inside them So I built this tool to make these export easier to browse.One thing I learnt while building is that neither ChatGPT nor Claude export enough info to reproduce everything you see in their app. The biggest gap is projects i.e if you use multiple projects, it is hard to reconstruct it.Everything is processed locally in your browser.
