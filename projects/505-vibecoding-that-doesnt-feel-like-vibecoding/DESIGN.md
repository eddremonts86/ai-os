# Vibecoding that doesn't feel like vibecoding! — Design direction

Like a structured editor, not a chat UI.

- Surface: spec panel + code panel + diff view.
- Color: ink + accent for "spec changed."
- Typography: monospace for code, sans for spec.
- No chat-style conversation in MVP.
