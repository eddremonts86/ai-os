# I built an app to filter noise from tech blogs and surface 6 quality engineering reads every day. How do I get more users?

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- RSS aggregation
- PostgreSQL
- Resend
- Stripe
- Vercel

## Architecture

Next.js; RSS aggregation pipeline; Postgres for posts + summaries; Resend for daily digest; Stripe for premium tier; Vercel.

## Milestones

- RSS ingestion
- Daily digest of 6
- Email + web delivery
- Stripe premium tier

## Risks

- Curation quality
- Source-list drift
