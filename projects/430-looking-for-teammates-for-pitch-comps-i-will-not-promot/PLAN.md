# Looking for teammates for pitch comps (I will not promote)

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- PostgreSQL
- Supabase Auth
- Resend
- Vercel

## Architecture

Next.js; Supabase Auth + Postgres; Resend for verification and match notifications; Vercel deploy.

## Milestones

- Profile + skill-tag schema with email-domain verification
- Skill-first search with deadline filter
- Mutual-interest handshake + private chat
- Public "next competitions" calendar (community-edited)

## Risks

- Spam and ghosting are the two real risks
- Verification mitigates the first; reminders mitigate the second
