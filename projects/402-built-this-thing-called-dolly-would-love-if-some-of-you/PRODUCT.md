# built this thing called dolly, would love if some of you tried it

> Auto-generated product brief.

## Value Proposition

A pre-run cost-preview AI media generation tool for creative professionals who are tired of credit-based billing surprises. Generic AI media tools in this space either hide the cost until after the run or expose only the day's pricing. This one surfaces the cost before the user spends the credit, with the model's input parameters on the same screen.

## Target Users

Primary: a creative professional — agency producer, freelance video editor, ad creative, social media lead — who is using AI media tools (Higgsfield, Runway, Pika, Suno, ElevenLabs) and is tired of running out of credits mid-job. Secondary: a small agency owner who is buying credits for a team and wants to forecast the monthly bill.

## Jobs To Be Done

When I (a creative professional or agency producer) am using AI media tools for a client job, give me a pre-run cost preview, a running credit ledger, and a model router so I can see what a generation costs before I run it and pick the cheapest upstream provider without leaving the tool.

## Success Metrics

1. The poster (or a comparable creator) can name, after one use, the cost of a specific generation before running it.
2. A creator can export a CSV of every generation they ran in the month, with the parameters and the cost, at the end of the month.
3. A creator switches between three upstream providers (image, video, voice) without losing the cost preview.

## Competitive Landscape

The market the creator operates in today is a mix of single-modality AI tools (Runway, Pika, ElevenLabs, Suno) and bundled AI creative platforms (Higgsfield, Krea, Adobe Firefly). None were named in the post — the table is left empty until the first 5 user interviews populate it. Refusing to invent competitors is the same discipline as refusing to invent a price.

## Risks & Open Questions

- The credit math is the named differentiator. Any drift in the math (a hidden multiplier, a rounding error, a model-specific surcharge) breaks the trust the post is built on. Mitigation: ledger entries are immutable and visible to the user.
- Upstream provider pricing changes every quarter. The cost preview must be re-validated on every change, not just on the user's next run.
- One poster is not a market. The credit-math fatigue must show up in 3+ comparable creators or the plan is solving a one-off.
- The post is a launch announcement. The MVP fails if it ships without a real creator using it for a real client job — the launch is the proof, not the blog post.
