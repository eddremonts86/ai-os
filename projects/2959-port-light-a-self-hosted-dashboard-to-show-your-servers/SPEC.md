# Port-Light – A self-hosted dashboard to show your server's port usage

## Problem

I make this tool, a self-hosted dashboard, to show which host ports are taken, as a traffic-light grid. All the reason because I'm a home server enthusiast, but have a chaotic and terrible memory.
It can aggregate ports from your different hosts and VPS as long as the network is reachable. And it merges three local sources into one grid: host listen tables, Docker API, and Compose files.
As a beginner, I am open to everyone's comments, and if there are better similar tools, please tell me about them to help me refer to them for learning, thanks.
