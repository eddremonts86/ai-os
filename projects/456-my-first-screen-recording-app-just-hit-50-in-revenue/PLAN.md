# My first screen recording app just hit $50 in revenue.

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Tauri
- Rust
- PostgreSQL
- Lemon Squeezy
- Vercel

## Architecture

Tauri shell + Rust core for recording; Next.js for marketing / license server; Lemon Squeezy for payments; Vercel.

## Milestones

- Native recording + system audio
- Built-in trim + zoom-pan
- Export to MP4 / GIF / share link
- Lemon Squeezy license flow

## Risks

- Native desktop support cost
- Editor scope creep
