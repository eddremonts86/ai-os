## Design direction

The user is a newcomer under daily stress. The visual register is calm, evidence-led, and language-respectful: large type, no urgency, multilingual labels in their own script wherever the user is reading.

Three principles drive the screen:

- **Evidence is the headline.** A place's evidence tag ("served immigrants from Russia, Ukraine, Syria — last confirmation: March 12") sits at the top of the profile. A star rating the platform invents is not shown.
- **Language-respectful typography.** A label in Russian, Arabic, or Chinese uses that script and font; the page never substitutes Latin-only text. The reader's chosen language sets the type system.
- **No decoration in the search path.** The search surface is a single input ("Where are you from? What do you need?") followed by results. There is no onboarding tour, no upsell, no marketing banner.

The MVP surface is functional: a search, a place profile, a Q&A thread, a confirmation action. There is no public marketing site beyond a single explanatory page.
