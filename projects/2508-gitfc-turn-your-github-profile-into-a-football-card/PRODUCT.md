## Value Proposition

_Based on source brief:_ I Built GitFC because I always wanted to see how an activity of Github would look like if treated like football player stats.
Here you include your github username and it generated an EA FC style card.
It will tell you an overall rating and stats like passing , shooting which would be based on your github activity like commits , PRs closed and so on.
There are also different card types based on roles included by me .The site is live and doesn't require an account, so you can try it directly:
