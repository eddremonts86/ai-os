# toca.la - song writer's companion app

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Web Audio API
- PostgreSQL
- Stripe
- Resend
- Vercel

## Architecture

Next.js; Web Audio API for playback; PostgreSQL for projects + audio metadata; Stripe for paid tier; Resend for digest; Vercel.

## Milestones

- Lyric editor with verse / chorus / bridge sections
- Per-section audio attachment
- Project library + versioning
- Stripe paid tier

## Risks

- Niche market size
- Audio storage cost
