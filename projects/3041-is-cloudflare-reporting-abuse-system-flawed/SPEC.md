# Is Cloudflare reporting abuse system flawed?

## Problem

Disclaimer: NET shareholder since 2019 here.Some days ago a redditor was looking for help after getting his credit card charged on a fraudulent e-commerce website.Fraudulent: hxxps://nestmyhaus[.]com Original: https://www.leroymerlin.it/I did a whois and found that DNS records are managed by CF. I submitted an abuse report via the form which was rejected 20 minutes later. Emails to abusereply@cloudflare.com have been automatically rejected. Can’t submit a second report with the same hostmane. The malevolent website is still out there probably taking other victims.Honesty this feels exactly the same as reporting posts on social media, A total waste of time. Why does CF even provide that form?Ranting about this here on HN as this has been proven determinant in the past.
