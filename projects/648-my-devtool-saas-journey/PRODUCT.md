## Value Proposition

One API for WhatsApp, email, and iMessage outbound — drop in the npm package and ship.

## Target Users

Agent developers ("open claw" deployments) who want channel plumbing they do not have to rebuild per provider. Indie hackers and small studios who found the project via GitHub trending.

## Jobs To Be Done

- When my agent needs to send WhatsApp, swap in the adapter instead of writing the integration.
- When I want to switch providers, change one config field.
- When I scale past indie volume, get a managed plan with higher throughput and SLAs.

## Success Metrics

- npm install rate (already strong: GitHub trending #9).
- Conversion from free install to paid plan (the poster's open question).
- Outbound messages per active account per day.
