# Founder POV — Design direction

Like a doctor's intake form, not a security vendor landing page.

- Surface: single-page audit + remediation list.
- Color: ink + accent for "do today."
- Typography: sans for questions, monospace for remediation steps.
- No "book a demo" CTA.
