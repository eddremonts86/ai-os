# Klisi – a GTK4/Adwaita callgrind profile viewer and generator

## Problem

For a long time, I had been in search of a callgrind profile viewer that would better integrate with the GNOME desktop environment.KCacheGrind is amazing, but I was looking for a GTK native alternative.Recently, I took an interest in Clojure, so I decided to combine the two in one project.The result of this is Klisi.Try it out and let me know what you think.You can read a small write-up about this first release on my blog[1].[1]: https://ckardaris.com/blog/2026/08/15/klisi.html
