# SaaSecure — fully local code scanner for AI-generated code

## Problem

The author is a former independent bug-bounty analyst (recognized by Google, Facebook and Microsoft under their VDPs) and a full-stack dev with 9+ years of non-AI coding experience. After trying AI coding agents this year, they noticed that the code blocks generated by agents repeatedly contain critical security issues — IDOR, CSRF, SQLi, CMDi — even when the agent's own review says the change is clean. Their published examples (a YouTube CSRF from 2018, a KPSC IDOR from 2019) prove that even mature products with proper headers ship these vulnerabilities. The author built SaaSecure to scan code for the OWASP top 10, missing `.env` entries in `.gitignore`, and credential leaks. The tool runs fully local — no code leaves the user's machine — supports 7 languages including PHP, JS and Python, and ships in two tiers: a $79 lifetime personal license (1 year of updates) and a $199 agency tier with 5 seats, a CI token, and an attested PDF report export. The author is selling the tool, not the company.

## Objective

Surface the security regressions that AI coding agents introduce into a codebase, before those patterns reach production. Detect the same class of vulnerabilities the author records in their bug-bounty history (IDOR, CSRF, SQLi, CMDi and the rest of OWASP top 10), plus the credential-leak and `.env` hygiene failures that are common with copy-pasted generated code, and present them in a form an engineer or an agency deliverable can act on.

## Target Users

Solo developers and small teams who ship code partly written by AI agents and want a fast local check before committing. IT agencies that need to produce a security report to a client on each release and want a CI-integrated scan with a PDF artefact. Secondary: security-conscious founders who want a "no code leaves the box" tool because their codebase is sensitive.

## MVP Scope

The four features the author explicitly listed: fully local execution, 7-language support (PHP and JS are named; Python and four others are implied), $79 lifetime license with 1 year of updates, and an agency tier ($199 / 5 seats / CI token / attested PDF export). Scan coverage targets OWASP top 10, missing `.env` in `.gitignore`, and credential leaks. The author is already selling from [saasecure.penqn.in](https://saasecure.penqn.in).

## Constraints

The author's credibility is the product: their VDP recognitions (Google, Facebook, Microsoft) are the only social proof surface in the source. The product must run fully local — that is the explicit privacy promise and the reason the SaaS is named "SaaSecure" rather than "SaaS". The lifetime-license model is a deliberate choice: the author rejected subscription in the source. CI integration and attested PDF export are gated to the agency tier, which limits how broad the public demo can be.
