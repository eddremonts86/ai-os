# I built an open-source, local-first work journal for developers

## Problem

Meridian is an open-source, local-first work journal for developers. It reconstructs your day from on-screen activity, creates daily summaries and standups, tracks where your time went, and drafts project ticket updates for review. Your activity is stored in an encrypted database on your machine, and Meridian is available under the MIT License.
