# Has anyone reinvented Intercom yet? (I will not promote)

## Problem

The poster runs a startup where onboarding often involves a lot of back and forth with customers to understand the product and get set up. They are looking for something like Intercom on steroids — an AI agent that can actually guide users through onboarding interactively, ideally with rich UI and even video, rather than just answering questions in chat. Anyone else have this problem or know a tool that solves it well? The post is a question, not a complaint. No country, no specific stack, no metrics were stated.

## Objective

Give a startup founder who is drowning in onboarding back-and-forth a named-comparison framework — the named Intercom-shaped tools that exist, the named AI-onboarding tools, the named gap (the named Intercom-on-steroids), the named build-it-yourself shape. The job is not to find the tool — it is to give the founder a named-decision framework so the tool-pick is a deliberate one, not a default 'use Intercom'.

## Target Users

Primary: a startup founder who is drowning in onboarding back-and-forth and wants the named-comparison framework for the named Intercom-shaped tools. Secondary: a head of customer success or growth at the same kind of company who is being asked to pick the onboarding tool and wants the named gap in front of them.

## MVP Scope

In scope for v1:

- A 'Intercom on steroids' framework: the named Intercom-shaped tools (Intercom, Drift, Zendesk Chat), the named AI-onboarding tools (named Outset, named Chatling, named Userflow), the named gap (rich UI, video, named interactive elements), the named build-it-yourself shape.
- A 'before you switch' checklist: the named preconditions (named onboarding volume, named team, named budget, named timeline).
- A 'first-12-months' sketch: the named monthly cost on each option, the named tool-fit trend, the named switch trigger.
- A one-page export the founder can drop into a Notion doc or a team thread.
