# Homelander – free desktop app that applies for apartments in Germany

## Problem

I built Homelander because searching for apartments in Germany was taking too much time.It collects listings from multiple searches on ImmoScout24 and applies for you. I decided to build it because alternatives were either too techy or too expensive (like 100 euros per months).I originally built it for myself, then released it as a free and open-source desktop app. The first release got much more attention than I expected, and the project is now at 92 GitHub stars.It currently supports Mac, Windows and Ubuntu Linux.GitHub: https://github.com/B1Z0N/homelanderI'd be interested in feedback, especially on the UX side and on what would make it more useful for apartment hunters.Disclosure: as you can see I used AI to make it faster, and for UI, since I am bad at it. But I spent a shitton of time on UX.PS: I heard some people found apartments using this app, but I must warn - this is a portfolio project and goes against the usage guidelines of IS24.
