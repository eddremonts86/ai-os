# Killgate Blueprint - A 6-agent AI operating system designed to kill bad SaaS ideas before you waste months building them

## Tech Stack

Chosen for this problem:

- TypeScript
- Claude API
- Anthropic API
- PostgreSQL
- Resend
- Vercel

## Architecture

TypeScript orchestrator; Claude API for reasoning; Anthropic API for evaluation; PostgreSQL for evidence trail; Resend for notifications; Vercel.

## Milestones

- 6-agent orchestration
- Public evidence trail
- Independent Evaluator with veto
- Verdict page per idea

## Risks

- Coordination complexity
- Evidence trail honesty
