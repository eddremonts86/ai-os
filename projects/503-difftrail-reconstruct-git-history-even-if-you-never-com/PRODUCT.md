# DiffTrail: Reconstruct Git history even if you never committed it

> Auto-enriched product brief.

## Value Proposition

DiffTrail: a tool that reconstructs a chronological diff trail from editor autosaves and workspace state, so you can recover history you never committed.

## Target Users

- Developers who lost work because they forgot to commit
- Solo founders iterating fast who forget intermediate steps
- Engineers who want a "what did I write yesterday?" tool

## Jobs To Be Done

When I forgot to commit and lost work, I want a tool that reconstructs a chronological diff trail from editor autosaves and workspace state, so I do not lose history I never committed.

## Success Metrics

- At least 100 active installs in pilot
- Self-reported "I recovered work" rate above 30%
