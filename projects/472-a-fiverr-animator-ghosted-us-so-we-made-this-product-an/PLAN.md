# A Fiverr animator ghosted us, so we made this product animation with 3 prompts and one HTML file

## Tech Stack

Chosen for this problem:

- Next.js
- TypeScript
- Anthropic API
- Lottie
- PostgreSQL
- Resend
- Vercel

## Architecture

Next.js; Anthropic API for prompt-to-scene; Lottie for animation primitives; Postgres for animations + briefs; Resend for export links; Vercel.

## Milestones

- Brief intake
- Prompt-to-scene generator
- HTML export
- MP4 export pipeline

## Risks

- Animation quality
- MP4 render cost
