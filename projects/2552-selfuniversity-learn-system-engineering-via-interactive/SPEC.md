# SelfUniversity – learn system engineering via interactive puzzles

## Problem

I'm 18, I've solved 826 problems on LeetCode with a 430+ day streak, and I can tell you, it's a dry platform for solving algorithmic little tasks, and it has nothing to do with education. I am not saying it is bad, LeetCode is actually awesome, but it just does not teach you anything.I came here to fix this exact problem.
When you want to solve a new problem, you often run into the fact that you're seeing it for the first time, especially the topics that are in there. And then going off to read lectures or articles is not ideal, because you need to solve the problem here and now (otherwise it'd be constant context switching), not waste a ton of time on it, especially on those complicated problem statements.All of the above can be applied to a lot of things in general, like reading docs, articles, AI slop, and other materials. The deal is simple: you find some info, read it, take notes, then you never come back to them (because it's long and boring to reread), and you forget it all.So I started fixing all of these problems — convenient, fast, always at hand, and it's selfuniversityWelcome:
https://selfuniversity.site
