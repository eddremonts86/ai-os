# Anyone here in a meteorology startup? I will not promote — Design direction

Honest, almost-utilitarian. The poster is a student trying to find a job; the directory should look like a working spreadsheet with good typography, not a marketing site.

- Primary surface: a sortable, filterable table. Each row is a company; columns are country, sub-niche, hiring status, last signal date.
- Secondary surface: a single company-detail page with role profiles and one-click subscribe to alerts.
- Color: muted blues and a single accent for "hiring now"; no decorative gradients.
- Typography: Inter for body, IBM Plex Mono for company slugs and tags so the directory reads like data.
- Do not invent a hero image of clouds or radar. There is no weather imagery in the source.
