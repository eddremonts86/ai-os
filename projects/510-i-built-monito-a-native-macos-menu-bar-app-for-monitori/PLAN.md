# I built Monito, a native macOS menu bar app for monitoring and managing VPS instances

## Tech Stack

Chosen for this problem:

- Swift
- SwiftUI
- macOS
- Nezha/Komari/NodeGet APIs
- SSH (NMSSH)
- StoreKit
- TestFlight

## Architecture

Swift + SwiftUI menu-bar app; native APIs for Nezha / Komari / NodeGet; NMSSH for SSH; StoreKit for Pro tier; TestFlight.

## Milestones

- Nezha / Komari / NodeGet dashboard integration
- Standalone SSH server support
- Menu-bar quick status
- Pro: SSH terminal + file + container management

## Risks

- API changes
- Native macOS support
