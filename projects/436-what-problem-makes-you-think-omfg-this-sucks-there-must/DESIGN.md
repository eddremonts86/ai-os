# What problem makes you think Omfg this sucks there must be a better way? (I will not promote) — Design direction

Like a public library card catalogue, not a startup pitch deck.

- Surface: a dense list of problem entries, each one card with original quote, source link, and tags.
- Color: ink + one accent for "frequent pain."
- Typography: serif for problem titles, sans for body, monospace for source URLs.
- No marketing illustrations. No "let's fix this together" hero.
